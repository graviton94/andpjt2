# 장르 점검 — 방치형 연쇄 퍼즐로서 상업적으로 충분한가 (11-28, 화면 세션)

기준은 이 장르에서 오래 살아남은 게임들의 공통 요소다(방치형 클리커, 머지·퍼즐 방치형, 블록 파괴 방치형). 각 요소를 현재 빌드와 비교하고 담당을 나눴다.

## 1. 첫 15분 측정 (힌트대로 직접 플레이, 스와이프당 4.5초)
| 시점 | 일어난 일 |
|---|---|
| 0:05~0:45 | Lv2→6, 6연쇄, 첫 앱 구매 (빠르고 좋음) |
| 0:45~3:00 | 앱 2개, Lv7~8 |
| 3:00~15:00 | Lv9~12, 앱 3개. **새 것이 2~5분에 하나** |
| 15분 내내 | 최고 연쇄 6에서 멈춤 |

- **문제: 3분 이후 공백.** 장르 기준은 첫 10분 동안 30~60초마다 눈에 보이는 진전(구매 가능, 해금, 보상)이다.
- 판 위에는 다음 목표가 보이지 않는다. 지갑 숫자만 오른다.

## 3. 이번 라운드에 화면 세션이 하는 것
1. **다음 목표 칩**: 판 위 오른쪽 위. 다음에 살 앱(아이콘 + 진행 링 + %)을 보여 주고, 살 수 있으면 반짝이며, 누르면 상점이 열린다. 살 앱이 없으면 다음 해금 레벨을 보여 준다.
2. **앱 도감**: 셰이드 타일. 전체 앱을 실루엣·발견·보유로 나눠 보여 주고, 앱마다 효과와 알림 문구를 담는다. 완성률도 표시한다. 보상은 밸런스 세션에 제안한다.
3. 레벨업 때 무엇이 열렸는지 한 줄로 알려 준다(새 앱, 카드, 강화).

## 4. 다른 세션·사용자에게
- 밸런스: 첫 15분 3분 이후 공백을 다음 지시서에 넣는다(해금 간격, 첫 15분 목표 지표).
- 발주: BGM(메인 루프, 타이틀, 피버/연쇄 레이어). 사용자 확인 후 발주서를 쓴다.
- 결정 필요: 경쟁 요소(일일 도전 주간 순위) 도입 여부.
