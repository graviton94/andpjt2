# 12 · 용어집

| 용어 | 코드 | 뜻 |
|---|---|---|
| 판 | `GameState.rows` | 알림 목록. 7~12줄 |
| 줄 · 알림 | `Row` | 앱 · 와일드 · 스팸 · 전화 · 이벤트 카드 |
| 수량 / 기준 | `count` / `threshold` | 줄의 알림 개수 / 폭발 기준(4) |
| 합치기 | `Beat.Merged` | 맞닿은 같은 앱(또는 와일드) 두 줄이 하나로 |
| 폭발 · 연쇄 | `Beat.Burst` | 기준 이상이 되어 터짐. 연쇄 번호 n마다 ×(1+n) |
| 과부하 · 파동 | `gauge`, `Beat.Wave` | 게이지 100에서 폭발한 앱의 숨은 알림이 ×3ⁿ 파동으로 |
| 과부하 깊이 | `overloadDepth` | 파동 수 |
| 샌드위치 | `sandwichPercent` | 새 줄이 두 칸 아래와 같은 앱으로 나와 A·X·A를 만드는 확률 |
| 와일드 | `RowKind.Wild` | 어떤 앱과도 합쳐지는 줄 |
| 점화제 | `igniterGaugePerTier` | 저티어 폭발이 게이지를 더 채우고 연쇄 번호를 올리는 역할 |
| 배터리 | `energy` | 행동력. 스와이프 1칸, 3초 충전 |
| 자동 정리 | `autoTarget` | 4.5초마다 단순 판단으로 미는 방치 기능 |
| P | `wallet`, `runEarned` | 정리 포인트. 지갑이자 점수 |
| 레벨 | `level`, `levelP` | 이번 회차 누적 P로 정해지는 해금 단계 |
| 티어 | `AppDef.tier` | 앱 등급 1~6. 알림 가치 ×10씩 |
| 덱 · 앱 슬롯 | `active`, `maxSlots/minSlots` | 판에 알림을 보내는 앱 목록과 그 개수 범위 |
| 이벤트 카드 · 이벤트 슬롯 | `EventCard`, `equipped` | P로 사서 별도 슬롯에 장착하는 특별 알림 |
| 시너지 | `synergySteps` | 덱 안 같은 권역·카테고리 개수에 따른 보너스 |
| 권역 · 카테고리 | `Region`, `Category` | 가상 시장 5 · 앱 분류 5 |
| 강화 · 마일스톤 | `appLevels`, `levelMilestones` | 앱 레벨, 10·25·50…단계마다 ×2 |
| 프로 버전 | `pro`, `proLevel` | 앱마다 한 번 사는 ×3 상위판 |
| 판 강화 | `Assist` | 과부하 깊이·샌드위치·넓은 알림창·와일드 (회차 안 구매) |
| 공장 초기화 | `factoryReset` | 환생. Lv25부터 |
| 백업파일 · 평생 백업파일 | `Backup.files`, `lifetime` | 환생 재화 / 지금까지 얻은 총량(가치 +5%/개) |
| 백업 상점 | `BackupItem` | 초기화에도 유지되는 영구 업그레이드 |
| 클라우드 동기화 | (계획) | 2차 환생 |
| 회차 | run | 공장 초기화 사이의 한 판 |
| 박자 | `Beat` | 판정 결과를 화면이 재생하는 순서 단위 |
| 오프라인 정산 | `settleOffline` | 접속하지 않은 시간의 수입 |
