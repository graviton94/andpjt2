# 17 · 수익화 (BM v2.1)

**이 장르 표준 P2W**: 유료재화가 진행 속도를 사고, 돈의 크기만큼 빨라진다(결정 기록 11-23). 광고는 적은 횟수로 확실한 보상, 꾸미기는 만족감 + 소량 시너지. **확률형(가챠)은 없다.** 무엇을 사든 결과가 보인다.

엔진: `core/.../Monetization.kt` (`Account`, `Shop`, `AdSlot`, `CreditItem`, `SpeedPass`, `AttendReward`), 수치는 `RuleSet` Monetization 묶음. 시뮬: `gradle -p tools/economy-sim run --args="money 84 2 all"` (프로필 5종 병렬, `SIM_RULES="키=값"`으로 수치 덮어쓰기, `ablate`로 광고 지면 하나씩).

## 1. 핵심 재화 4종

| 재화 | 성격 | 얻는 곳 | 쓰는 곳 |
|---|---|---|---|
| **P** (포인트) | 회차 재화. 초기화하면 사라짐 | 스와이프, 자동 정리, 오프라인, 광고 ×2, 시간 도약 | 앱 구매·강화, 카드 |
| **데이터** (유료, 코드 `credits`) | 영구 | 결제(데이터 충전), 출석, 일일 미션, 광고 상자, 패스 | 프리미엄 ★, 오버클럭, 시간 도약, 부스트, 보조배터리, 백업 부스트, 꾸미기 |
| **백업파일 · GB** (환생) | 영구 | 초기화 · 동기화 | 백업 · 클라우드 상점. 직접 판매 없음 (백업 부스트, 속도 구독 배율로 간접) |
| **배터리** (에너지) | 12칸, 3초마다 1칸 | 시간, 보조배터리 | 직접 스와이프 1칸 |

데이터 아이콘은 초록 신호 막대, GB는 하늘색 구름(같은 용량 느낌이라 아이콘·색으로 구분). 에셋은 `docs/design/ui-assets/currency/`.

## 2. 단위 경제 (가정치 → 소프트런치 수치로 교체)

| 유형 | 계산 | 월 순수익 |
|---|---|---|
| 광고 꾸준히 | 하루 5회 × 월 20일 접속 × 보상형 eCPM ₩15,000(1회 ₩15) | ≈ ₩1,500 |
| 월간 패스 ₩5,500 | VAT 제외 ₩5,000 × 구글 85% | ≈ ₩4,250 |
| 터보 ₩33,000 | 같은 방식 | ≈ ₩25,500 |
| 울트라 ₩99,000 | | ≈ ₩76,500 |

- 목표 생애 가치(LTV) ≥ CPI(국내 안드로이드 캐주얼 ₩2,000~4,000). 평균 20일 플레이 기준 ARPDAU ₩150~200.
- 매출의 무게는 결제자(접속자의 2~3%, 월 ₩5만 안팎). 그래서 **돈을 쓴 만큼 확실히 빨라야** 하고, 광고는 "볼 만한" 수준이면 된다.
- 고과금은 한 달이면 이 장르 생애 과금 기대치에 가깝다. Lv124 이후에도 레벨은 무한, 프리미엄 ★·업데이트 팩·순위표로 이어간다.

## 4. 시간을 파는 장치

레벨 곡선이 레벨당 ×2.3이라 수입 배율은 몇 레벨밖에 못 당긴다. 후반 성장은 **초기화 횟수(=시간)**가 정하므로 돈은 시간을 사게 한다.

| 장치 | 효과 | 얻는 곳 |
|---|---|---|
| **오버클럭** | 게임 속도 ×3: 배터리 충전(직접 스와이프는 최소 1초), 자동 정리, 오프라인 누적 | 데이터 1시간 40 (하루 24) · 광고 1시간 (하루 2) · 패스 매일 3시간 · 출석판 |
| **속도 구독** | 30일 상시 속도 + 환생 재화 배율 + 오프라인 레벨 상한 배율 (돈 낸 속도가 과열 보호에 버려지지 않게) | 터보 ×3.5 · 백업파일/GB ×1.75 / 울트라 ×8 · ×4 |
| 시간 도약 | 자동 정리 몫(40%)으로 2시간분 P 즉시 (레벨 +1까지) | 데이터 80 (하루 12) · 광고 1 |
| 수입 부스트 | 1시간 모든 수입 ×2 (수입 속도 계산에서는 제외) | 데이터 40 (하루 6) · 광고 2 |
| 백업 부스트 | 다음 초기화 백업파일 ×2 | 데이터 150 (초기화마다 1) · 출석판 |
| 보조배터리 | 배터리 가득 + 6칸 초과 | 데이터 10 · 광고 2 · 출석판 |

## 5. 프리미엄 버전 (데이터 영구 성장 축)

- 앱마다 ★0~★5, 해금했던 앱이면 언제든, 초기화·동기화에도 유지. 프로 버전(회차 안 ×2)과 별개.
- 효과 **★마다 그 앱 가치 ×2** (★5 = ×32). 최상위 앱이 수입 대부분을 내므로 사실상 전체 배율. ★3 고유 효과 강화 연출, ★5 금빛 카드·금빛 깨짐.
- 가격: ★0→★5 전체 = 6,000 × 2^((티어−1)/4.5) / 4, 별 단계 비율 5·10·17·28·40%.

| 티어 | ★1 | ★2 | ★3 | ★4 | ★5 | 합계 |
|---|---|---|---|---|---|---|
| 1 | 75 | 150 | 255 | 420 | 600 | 1,500 |
| 5 | 140 | 280 | 470 | 780 | 1,110 | 2,780 |
| 10 | 300 | 600 | 1,020 | 1,680 | 2,400 | 6,000 |

무과금 12주 무료 데이터(출석 + 미션) ≈ 6,800 → **10티어 ★5 1개 / 중간 티어 2개 / 1티어 4개** (테스트가 지킨다).

## 6. 30일 연속 출석판

**개근이 끊기면 1일차부터.** 평일은 재화를 번갈아, 10·20·30일은 첫 결제를 고민하게 할 만큼 크게. 오버클럭·★ 선택권으로 **유료 상품을 맛보게** 한다.

| 구간 | 평일 (순환) | 큰 날 |
|---|---|---|
| 1~9 | 데이터 30·40·40, 보조배터리 ×2, **오버클럭 1시간 체험(3일)**, 부스트, 시간 도약 | **10일** 데이터 200 + 오버클럭 2시간 + 백업 부스트 |
| 11~19 | 데이터 40·50·50, 같은 순환 | **20일** 데이터 300 + **프리미엄 ★ 선택권 1** + 시간 도약 2 |
| 21~29 | 데이터 50·60·60, 같은 순환 | **30일 개근** 데이터 600 + **★ 선택권 2** + 오버클럭 6시간 + 백업 부스트 2 + 칭호 "알림 개근왕" + 개근 전용 테마(꾸미기) |

한 판 데이터 1,520, ★ 선택권은 아무 앱을 ★2까지 올린다(무료 유저 진행이 과하게 당겨지지 않게).

## 7. 보상형 광고 (강제 광고 없음)

| 지면 | 보상 | 하루 상한 |
|---|---|---|
| 최고 기록 ×2 | 정산이 회차 최고를 넘는 순간, 그 P 한 번 더 (Lv20부터, 레벨 +1까지) | 2 |
| 오프라인 ×2 | 당일 가장 최근 양수 복귀 지급을 한 번 더. 레벨 +1 상한, 복귀 제안 소진 시 종료 | 1 |
| 수입 부스트 | 1시간 ×2 | 2 |
| 오버클럭 | 1시간 ×3 | 2 |
| 시간 도약 | 2시간분 | 1 |
| 보조배터리 | 최대치까지 채우고 6칸 초과 충전 | 2 |
| 데이터 상자 | 데이터 10 | 1 |
| 무료 강화 | 현재 가장 높은 티어의 장착 앱 +5 | 1 |

월간 패스 이상은 같은 지면별 상한으로 광고 없이 받는다. 사용 횟수는 UTC 날짜를 기준으로 갱신한다. 코어 지면별 총합 상한은 12회이며, 시뮬의 광고 프로필은 하루 5회 한도를 선택한 비교군이다. 지면 간 공유 쿨다운은 두지 않는다. 부스트와 오버클럭은 만료 시각에 시간을 연장하며, 연속 같은 영수증 지급은 차단한다. 복귀 광고 제안과 다음날까지 +70% 혜택은 서로 다른 효과다.

첫 구매 추가분은 데이터 팩 공통 1회, `min(기본 지급, 1,200)`이다. 월 구독의 환산은 30일 모두 청구한 데이터와 오버클럭(시간당 40)을 합친 금액이다. 광고 제거, 상시 속도, 환생 배율은 데이터 환산에서 따로 평가한다. 선택권 한 장의 표준 환산은 기존 티어 5 ★1·★2 합산 420이다. 선택권 실사용은 ★1단계 증가이며 ★2까지만 가능하다. 백업 부스트는 데이터 150, 다음 초기화의 파일 ×2, 초기화까지 중복 예약 불가다.

별 강화는 앱별 ★1~5이고 실제 단계별 데이터와 배율은 [premium-star-costs.csv](../balance/launch-v1-data/premium-star-costs.csv)에 있다. 스타터 중복 행을 정리했다. 성장 지원 팩·꾸미기·EX는 후속 기획 문서의 승인 절차를 따른다. 배포 목록에는 위 11개 상품이 있다.

### 10시드 검증에서 적용한 오프라인 보정

보상형 광고를 직접 본 날과 다음 UTC 날짜, 또는 패스 이용 중에는 오프라인 정산액이 70% 증가한다. 두 조건이 겹치면 +70%를 한 번 적용한다. 울트라는 패스 보너스를 적용한 정산액에 1.5를 곱해 총 2.55배를 지급한다. 최종 지급은 속도 구독과 오프라인 레벨 상한을 함께 적용한다. [패스 오프라인 보너스 검증](../balance/offline-pass-review.md)
