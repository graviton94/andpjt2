# 17 · 수익화 상세

결정 기록 기준: **유료 가챠(확률형 아이템) 없음**, 강제 전면 광고 없음, 보상형 광고 + 비확률 직접 판매 + 비확률 패스. 단계적 도입은 마스터 플랜 "수익화 단계"(출시 후 0~12주)를 따른다.

## 1. 원칙

| 원칙 | 기준 |
|---|---|
| 확률 없음 | 돈이나 광고로 얻는 모든 보상은 **사기 전에 정확히 보인다** |
| 진행을 사지 않는다 | 유료 보상은 시간 단축·편의·꾸미기. 백업파일·GB를 직접 팔지 않는다(곡선이 무너진다) |
| 하드 재화 없음 (출시) | 원화 가격을 바로 표시. '다이아' 같은 중간 재화는 두지 않는다(투명성, 정책 검토 간소화). 필요해지면 v2에 재검토 |
| 광고는 선택 | 보상형만. 안 봐도 기본 보상 전액(결정 기록). 하루 횟수 상한 |
| 무료로 끝까지 | 경제 목표(12주에 마지막 앱)는 **무과금·무광고** 시뮬레이션 기준이다 |

## 2. 보상형 광고 지면

| 지면 | 보상 | 하루 상한 | 도입 | 비고 |
|---|---|---|---|---|
| 오프라인 정산 ×2 | 정산 P 한 번 더 | 2회 → 실험 후 3회 | 출시 0주 | 미시청 10~20% holdout 측정 |
| 배속 부스트 | 30분 동안 자동 정리 2배 | 2회 | 2주 | 방해 금지와 겹치면 더 빠르지 않음(상한 2배) |
| 2배 보상 (연쇄 직후) | 3연쇄 이상 직후 그 스와이프 P 한 번 더 | 3회 | 4주 | 판 흐름을 끊지 않게 결과 연출 뒤에만 |
| 무료 강화 | 덱 앱 하나 강화 +5 | 1회 | 4주 | 저티어 따라잡기 체감 |

광고 제거 구매자는 위 보상을 **광고 없이 같은 상한으로** 받는다.

## 3. 직접 판매 (원화, 가안)

| 상품 | 가격 | 내용 | 도입 |
|---|---|---|---|
| 광고 제거 | ₩6,900 | 보상형 광고 보상을 광고 없이 받음(상한 동일) | 3주 |
| 스타터 팩 (1회) | ₩2,500 | 꾸미기 테마 1 + 배속 부스트 3회 + 시작 자금 2배(첫 초기화 전까지) | 3주 A/B |
| 배터리 팩 | ₩1,200 | 배터리 최대 +2 영구 (회차 무관) | 5주 |
| 꾸미기 테마 | ₩2,500 각 | 판·패널 색 테마 (해금표 무료 테마와 별개 라인) | 5주 |
| 파쇄 효과 팩 | ₩1,900 각 | 폭발 연출 | 5주 |
| 효과음 팩 | ₩1,900 각 | 스와이프·폭발 사운드 | 5주 |
| 정주행 팩 | ₩4,900 | 오프라인 상한 +4시간 영구 | 5주 (시뮬 후, 오프라인 몫 50% 넘지 않게) |

가격은 Play 지역 가격표 기준으로 맞춘다. 모든 상품에 "무엇이 바뀌는지"를 한 줄로 적는다.

## 4. 패스 (비확률)

| 항목 | 내용 |
|---|---|
| 주기 | 4주 시즌, 시즌 테마(예: "새학기 알림 폭탄") |
| 진행 | 일일 미션 3개·주간 미션 5개로 패스 포인트. 미션은 플레이 행동(폭발·연쇄·초기화·덱 시너지)만, 결제 미션 없음 |
| 무료 트랙 | 30단계: 배속 부스트, 꾸미기 조각, 칭호 |
| 유료 트랙 ₩5,500 | 같은 30단계에 꾸미기 테마 1·파쇄 효과 1·효과음 1 완성품 + 배속 부스트 추가. **백업파일·GB 없음** |
| 도입 | 9~12주 소프트런치 A/B (패스 구매군/비구매군 리텐션·ARPDAU) |

## 5. 경제 안전장치

- 시뮬레이터에 "광고 시청자" 프로필 추가 예정: 오프라인 ×2 하루 2회 + 배속 부스트 하루 2회. 이 프로필에서도 마지막 앱이 **9주보다 빨라지지 않게** 상한을 정한다.
- 영구 상품(배터리 팩·정주행 팩)은 오프라인 몫이 50%를 넘지 않는지 시뮬로 확인 후 출시.
- 지급은 `claim_id` 멱등, 원자적 저장(18장 운영 기반).

## 6. 표기·정책

- 상점 첫 화면에 "확률형 상품 없음" 표기.
- 미성년 결제 취소·청약철회·Play 환불 안내 링크.
- 광고 SDK 데이터 흐름과 Play Data safety 일치, 맞춤 광고 동의(UMP).
