## 화면 지도

```text
┌─ 상태표시줄 HUD ─ 시계 · 이벤트 · 신호(과부하) · 배터리(행동력 9/12)
├─ 헤더 ─ P 지갑 · Lv · 다음 레벨 막대 · 총 배율
├─ 원형 타일 4개 ─ 자동 정리 · 과부하 링 · 2배 보상 · 알림훈련
├─ 게임판 ─ 알림 카드 7~12줄 (스와이프)
└─ 아래로 끌어내리기 → 패널
     ├─ 큰 버튼: 앱 상점 · 앱 강화
     ├─ 토글 8: 진동 · 움직임 줄이기 · 미리보기 · 다크 모드 · 기록 · 일일 도전 · 광고 보상 · 도움말
     ├─ 슬라이더: 배경음 · 효과음
     ├─ 미디어 카드: 배경음 트랙
     └─ 큰 버튼: 최고 기록 · 일일 도전
```

## 시트(패널에서 여는 화면)

| 시트 | 내용 | 핵심 UX 규칙 |
|---|---|---|
| 앱 상점 | 앱 24종(잠김 포함), 프로 버전 | 다음 해금까지 남은 레벨·초기화 횟수를 표시. 티어 칩, "알림 가치 ×10" |
| 앱 강화 | 보유 앱 강화 | **x1 / x10 / Max / 모두 강화**. "마일스톤까지 N단계" 강조 |
| 덱 편집 | 앱 슬롯 최소~최대, 이벤트 슬롯 | 시너지 미리보기(권역·카테고리 개수와 보너스), 최소 미만이면 저장 불가 |
| 판 강화 | 4종, 레벨별 최대 | 현재 단계/최대, 다음 최대가 열리는 레벨 |
| 공장 초기화 | 받을 백업파일, 예상 가속 | "지금 초기화하면 모든 가치 +X%, 이번 회차 T → 예상 T′" (사례조사 23) |
| 백업 상점 | 16항목, 초기화 횟수 잠금 | 무한 싱크 / 유한 유틸 / 점근 포화 유형 아이콘 |
| 기록 | 최고 스와이프, 최고 연쇄, 회차 기록, 해금 연대기 | 회차별 최고 레벨 그래프 |
| 일일 도전 | 고정 시드 60초 기록전 | 키 2개/일, 보상은 꾸미기·조각 |

## 숫자 표기

- 기본: 글로벌 방치형 표준 약어 `999 → 1.23K → 12.3K → 123K → 1.23M → B → T → aa, ab … zz`. 유효숫자 3자리, 뒤 0 생략, 내림(가진 것보다 크게 보이지 않게). 모든 재화(P·백업파일·GB)와 점수에 같은 규칙. 엔진 `short()`.
- 설정: 과학 표기(1.5e42). 한국어 단위(만·억·조)는 쓰지 않는다.
- 고정폭 숫자(tnum), 카운트업은 결과 박자 길이에 맞춤.

## 결과 연출 순서

`밀기(얇은 탭) → 합치기(접촉 섬광) → 폭발(히트스톱·셰이크) → 4단 점수 팝업(기초 → +배율 → ×배율 → 연쇄, 0.1초 간격, 음정 상승) → 과부하 파동(상태표시줄까지) → 새 줄 등장`. 빠른 자동 모드에서는 즉시 합산 토글.

## 첫 경험

- 첫 스와이프: 작은 성공(9 P)이지만 연출은 크게(결정 3 + 사례조사 21).
- 첫 초기화 직후 첫 판: 큰 연쇄가 나도록 배열된 판으로 "환생이 통했다"를 체감.
- 패러다임 전환 시점마다 한 줄 안내(자동 정리, 덱, 초기화, 프로, 클라우드 동기화).

## 접근성

최소 48dp, 색만으로 상태 전달 금지, TalkBack 정리 동작, 움직임 줄이기(셰이크·섬광·파티클 끔), 큰 글자 200%.
