# 01 · 마스터 개발 플랜

1인 Android 개발 기준. 방치형·머지형 증분 퍼즐의 일반적인 순서(규칙 → 경제 → 그레이박스 → 수직 슬라이스 → 메타 → 출시 준비 → 테스트)를 따른다. **각 단계는 통과 조건을 만족해야 다음으로 간다.** 기간은 가안.

## 단계

| 단계 | 결과물 | 통과 조건 | 상태 | 기간(가안) |
|---|---|---|---|---|
| **1. 코어 규칙 + 디자인 시스템** | `core/` 규칙 v3, 디자인 토큰·시트 | 규칙 테스트 통과, 예시가 문서와 일치 | ✅ 완료 | — |
| **2. 경제 + 콘텐츠 표** | 시뮬레이터, 경제 v0.4, 해금표, 참조표 자동 생성 | 8주 시뮬 목표(04번 1장) | 🟡 v0.4 · v0.5 과제 남음 | 1~2주 |
| 3. 그레이박스 앱 | `app` → `core` 연결, 토큰 테마, 판·HUD·패널·시트 최소 구현, 저장 | 내부 30분 플레이에서 덱 교체·초기화 이해, 저장 복구 | ⬜ | 3주 |
| 4. 수직 슬라이스 | 첫 1일 분량을 출시 품질로: 튜토리얼, 타격감(모션 토큰 A/B), 햅틱 단계 대체, 사운드, 4단 점수 연출 | 신규 10명 중 8명 10초 안 첫 스와이프, 7명 연쇄 뒤 계속 | ⬜ | 3주 |
| 5. 메타 시스템 | 시간형 카드, 기본 돌발 추가, 일일 도전, 꾸미기, 2차 환생, 자동화 | 8주 시뮬 + 내부 장기 플레이 2주 | ⬜ | 4주 |
| 6. 출시 준비 | 보상형 광고, IAP 4계층(단계적), 텔레메트리, 원격 규칙, 스토어 | 지급·복원 중복 테스트, 실기기 성능, 정책 검토 | ⬜ | 3주 |
| 7. 비공개 테스트 → 소프트런치 | Play 비공개 테스트 → 국내 소프트런치 | D1 ≥ 40%, D7 ≥ 18%, 세션 ≥ 12분, 첫 초기화 완료율 ≥ 35% | ⬜ | 4주+ |

## 2단계 남은 일 (지금)

1. 6티어 시점 보정, 강화 성장률 티어별 차등, 대량 구매.
2. 오프라인 효율 기준 변경.
3. 문서뿐인 해금 콘텐츠 중 경제 영향이 큰 것(돌발 3종) 엔진 반영 → 재측정.
4. 고유 효과 v3.1 (앱 24종) — 수치 영향이 커서 2단계 안에서 처리.
5. 사례조사 묶음 A 발주·반영.

## 수익화 단계 (6~7단계)

조사 C·D 반영 ([13번](13-research-A-F.md)). **유료 가챠(확률형 아이템)는 하지 않는다.** 강제 전면 광고 없음.

| 출시 후 | 상품·노출 | 진입/중단 게이트 (가설) |
|---|---|---|
| 0~2주 | 보상형 광고 1종: 오프라인 정산 ×2, 하루 2회부터. 미시청 10~20% holdout | D1·D7 집계 유효, 지급 누락 0, 시스템 UI 혼동 신고 0 |
| 3~4주 | 광고 제거(무엇이 제거되는지 명시), 비확률 고정 스타터 팩 A/B | 구매 후 리텐션 악화 없음, 광고+IAP 합산 매출 비교 |
| 5~8주 | 고정 아이템 팩, 고정 보상 시즌 미션 | D14·D30, 환생 도달 분포 |
| 9~12주 | 비확률 패스 소프트런치 A/B | 패스 구매군/비구매군 리텐션·ARPDAU |

## 출시 준비 체크리스트 (6단계)

- 첫 실행·스토어 스크린샷에 "가상 스마트폰 UI를 활용한 퍼즐 게임" 표기, 스토어 문구에 "실제 기기의 알림·배터리·설정에 영향을 주지 않습니다".
- 상태표시줄·빠른 설정은 고유 픽토그램·서체·색. 실제 OS 경고 문구 금지. OS 푸시 알림은 게임 알림만.
- 앱 24종 이름·아이콘 상표 검색(KIPRIS·스토어·검색 변형) 기록. 고위험 후보(톡탁톡, 페이한칸, 숏츠한편) 대체명 준비.
- 광고 ID·SDK 데이터 흐름과 Data safety 일치, 개인정보처리방침, 청약철회·미성년 결제 취소·Play 환불 안내.
- 보상 `claim_id` 멱등 지급, 원자적 저장, Auto Backup 복원 테스트, 시간 조작 방어(같은 부팅 단조 시계).
- 햅틱 QA 매트릭스: Galaxy(One UI)·Pixel·보급형·에뮬레이터.
