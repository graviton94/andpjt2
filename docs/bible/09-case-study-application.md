# 09 · 사례조사 적용 매트릭스

출처: 《연쇄 블록 파괴형 머지·인크리멘탈 스코어링 게임 설계 마스터 블루프린트 및 밸런스 데이터시트》(2026, 24쪽, 이하 "보고서"). 보고서는 8×8 색 블록 연쇄 게임을 가정한다. 우리 게임은 **세로 알림 줄의 연쇄(1차원 보드) + 구매로만 오르는 앱 티어 + 덱**이라 그대로 옮길 수 없는 부분이 있다. 항목마다 **채택 / 변형 / 보류**를 정하고, 우리 쪽 근거(시뮬레이션·결정)를 적는다.

## 3. 보고서와 다르게 가는 이유 (요약)

- **1차원 판**: 알림창이라는 화면 판타지 때문에 줄 단위 연쇄다. 퍼콜레이션 수치 대신 샌드위치 확률·판 길이·와일드가 같은 역할을 한다.
- **판 안 머지 진화 없음**: 사용자 결정 2. 티어 상승은 상점과 덱 교체로만. 머지의 "보드 효율" 문제는 덱 크기와 최소 슬롯이 대신 만든다.
- **더 긴 장기 페이싱**: 보고서의 Run 1 25분 · Run 10 150분보다 길게, "환생 없이 한 달 넘게 해도 마지막 앱이 어렵다"(사용자 판단)를 목표로 한다.
