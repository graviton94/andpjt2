# 00 · 비전과 필러

## 한 줄

**스마트폰 알림창을 한 손으로 무너뜨리는 방치형 연쇄 퍼즐.** 알림 한 줄을 밀면 같은 앱끼리 맞닿아 터지고, 산 앱과 배율이 같은 스와이프를 수십 자리 큰 숫자로 바꾼다. 막히면 기기를 "공장 초기화"해 더 깊이 간다.

## 플레이어가 기억할 것

1. **밀면 터진다** · 한 손가락, 한 번의 스와이프로 판이 바깥쪽으로 풀린다.
2. **내가 고른 덱이 숫자를 만든다** · 같은 스와이프가 앱·강화·시너지에 따라 자릿수가 바뀐다.
3. **초기화할수록 더 멀리** · 회차마다 백업파일이 쌓이고 지난번 최고 레벨을 넘는다.

## 필러

| 필러 | 약속 | 지키는 장치 |
|---|---|---|
| 손맛 | 지울 때 찰칵, 붙을 때 쿵, 터질 때 판 밖까지 흔들린다 | 히트스톱·셰이크·햅틱·사운드를 한 박자로 ([디자인 시스템](../design/design-system.md) 7장) |
| 결정 | 무엇을 밀지, 어떤 덱을 짤지, 언제 초기화할지가 실제로 결과를 바꾼다 | 직접 플레이 = 자동의 2~3배, 시너지 덱 > 최소 덱 (시뮬레이션) |
| 성장 | 숫자는 기하급수로 커지고 해금은 촘촘하다 | 레벨마다 해금 하나 이상, 레벨 = 누적 P의 지수 |
| 귀환 | 접속할 때마다 쌓인 것과 열린 것이 있다 | 오프라인 정산, 초기화마다 새 백업 항목, 일일 도전 |
| 정직 | 기다림을 파는 과금, 강제 광고, 숨은 확률이 없다 | 선택형 보상 광고만, 꾸미기 중심 결제, 공식 투명 표기 |

## 대상

- 1차: 짧은 세션(3~5분)을 하루 여러 번 하는 국내 Android 캐주얼 사용자. 숫자가 커지는 게임과 정리 쾌감을 좋아함.
- 2차: 빌드·효율을 계산하는 방치형 마니아. 공식 공개, 과학 표기, 덱 실험을 즐김.

## 하지 않는 것

- 실제 OS·제조사·서비스의 로고·이름·아이콘 모방 (안드로이드 공통 문법만 차용).
- 실패로 진행을 잃게 하기 (실패 상태 없음, 결정 7).
- 판 안의 아이템 진화 머지 (티어는 구매로만, 결정 2).
- 시간 건너뛰기 과금, 강제 전면 광고.

## 차별점

| 유사 장르 | 그들 | 우리 |
|---|---|---|
| 방치형 클리커 | 버튼·생성기 | **알림 줄 연쇄 퍼즐**이 생산 수단 |
| 머지 게임 | 보드에서 합쳐 진화 | **덱으로 판에 나올 앱을 고른다**, 합치면 터짐 |
| 블록 파괴 방치형 | 공·벽돌 물리 | **시스템 UI 판타지**: 상태표시줄 HUD, 끌어내리는 메뉴 |
| 로그라이트 빌드 | 런마다 처음부터 | 회차는 초기화되지만 **백업파일이 영구히 쌓임** |
