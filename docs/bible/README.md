# 알림 청소부 · 게임 바이블

> 스마트폰 알림창을 한 손으로 무너뜨리는 방치형 연쇄 퍼즐. 알림을 밀어 같은 앱끼리 터뜨리고, 고른 덱과 쌓인 배율이 같은 스와이프를 수십 자리 숫자로 바꾼다. 막히면 기기를 공장 초기화해 더 깊이 간다.

이 폴더가 프로젝트의 **단일 진입점**이다. 새로 합류한 사람(또는 에이전트)은 이 문서 → 00 → 01 → 02 순서로 읽는다. 각 문서는 정본 위치를 밝히고, 숫자는 코드에서 오거나 코드에서 생성된다.
