# 13 · 2차 사례조사(A~F) 반영

2026-11-23 수령. 원문 세 건: ①《Android 시스템 UI 연쇄 알림 방치형 게임 경제·환생·덱 시너지 및 라이브옵스 심층 설계 보고서》(A·B, 18쪽) ②《OS UI 판타지 모바일 F2P 게임 시장·법규·수익화 검증 보고서》(C·D, 11쪽) ③《오프라인 경제·자동화·부정 방어·타격감·Android 햅틱》(E·F, 10쪽). 발주 프롬프트는 [10번](10-research-brief.md).

판정: **채택**(그대로) · **변형**(우리 구조에 맞게) · **검증 후**(시뮬레이션·실험으로 확인한 뒤) · **보류/거절**.

## 1. 확정 결정

| 결정 | 근거 |
|---|---|
| **유료 가챠(확률형 아이템) 도입하지 않음.** 꾸미기·상품은 직접 판매만 | 사용자 결정 · C·D P0/3 · 게임산업법 확률 표시 의무(2024-03-22 시행) |

| 오프라인 보상의 기준 속도는 **자동 정리 속도(R_auto)**, 직접 플레이 속도가 아님 | E·F P0/1 |

| D1 | 한국 Android 퍼즐/방치형 D1/D7/D30·ARPDAU·결제 전환 **공개 근거 없음** | 수용 | 게이트는 사전 등록 가설로 운영, 출시 0~12주 실측. 참고치: AppMagic 상위 캐주얼 D1 37% · D7 18.5% · D30 8.5% |

| D5 | 미성년 결제 취소, 청약철회 안내, Play 환불, 광고 ID·Data safety, Families | 채택 | 출시 준비 체크리스트(6단계) |
