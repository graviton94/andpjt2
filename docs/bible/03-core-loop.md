# 03 · 코어 루프 요약

정본은 [코어 규칙 v3](../core-rules-v3.md)와 `core/` 기준 구현이다. 이 문서는 한 장 요약과 점수 파이프라인 표기다.

## 세 겹의 루프

| 루프 | 주기 | 행동 | 결과 |
|---|---|---|---|
| 스와이프 | 3초 (배터리 1칸) | 알림 한 줄을 민다 | 합치기 → 폭발 → 연쇄 → 과부하 파동, P와 레벨 |
| 회차 | 수십 분~하루 | 앱 구매·강화·프로, 카드·판 강화, 덱 교체 | 티어 상승, 시너지, 레벨 해금 |
| 환생 | 하루~수일 | 공장 초기화, 백업 상점 | 평생 백업파일 보너스, 더 깊은 다음 회차 |
| (2차) | 수 주 | 클라우드 동기화 | 동기화 등급, 3갈래 트리 (계획) |

## 한 번의 스와이프

1. 배터리 확인(12칸, 3초 충전) → 민 줄 제거, 그 줄의 P(연쇄 ×1).
2. 뺀 자리 위아래가 같은 앱(또는 와일드)이면 합침, 4 이상이면 폭발 → 바깥쪽으로 반복.
3. 폭발마다 연쇄 번호 +1, 게이지 +12 (저티어는 점화제로 더).
4. 게이지 100 이상 + 폭발 → 과부하: 폭발 수량 × 3ⁿ 파동이 깊이만큼.
5. 새 줄이 위에서 내려온다(샌드위치 35%+, 와일드, 돌발, 장착 카드, @모두 예약).

## 점수 파이프라인 (Balatro식 4단 표기)

내부 계산은 하나의 곱이지만, 화면에는 **4단계로 나눠 차례로 보여 준다**(사례조사 채택 7).

| 단계 | 이름 | 우리 항목 | 표시 색 |
|---|---|---|---|
| ① 기초 | 칩 | 수량 × 10^(티어−1) × 강화 레벨 × 2^마일스톤 | 본문 |
| ② +배율 | 합산 | 권역 시너지 · 카테고리 시너지 · 누적 자릿수 보너스 | 포인트(블루/앰버) `+` |
| ③ ×배율 | 승산 | 프로 ×3 · 백업 가치 ×1.1ⁿ · 평생 파일 +5%/개 · 이벤트 | 연쇄 색(오렌지/골드) `×` |
| ④ 연쇄 | 폭발 | 연쇄 배율 (1+n) · 과부하 파동 3ⁿ | 연쇄 색 대형 |

## 직접 플레이 vs 자동

| | 직접 | 자동 정리 |
|---|---|---|
| 간격 | 배터리 3초 | 4.5초 (백업으로 −0.3초/단계) |
| 판단 | 판 전체를 본다 | 합치기 나는 가장 아래 줄 → 카드 → 스팸 문자 → 맨 아래 (백업 5단계부터 한 수 앞) |
| 효율 | 자동의 2.1~3.0배 | 기준 |
| 오프라인 | — | 최근 수입 속도 × 10%, 상한 1~4시간 |

## 상태와 결정론

- `GameState` 하나가 저장 단위. 시간은 입력(`now`)으로만, 난수는 SplitMix64 한 개의 `Long`.
- 같은 상태 + 같은 입력 = 같은 결과. 일일 도전과 서버 재현은 이 성질을 쓴다.
- 결과는 박자 목록(`밀기 · 합치기 · 폭발 · 파동 · 등장 · 무료 강화 · 레벨업`)으로 나오고, 화면은 재생만 한다.
