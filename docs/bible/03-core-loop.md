# 03 · 코어 루프 요약

정본은 [코어 규칙 v3](../core-rules-v3.md)와 `core/` 기준 구현이다. 이 문서는 한 장 요약과 점수 파이프라인 표기다.

## 세 겹의 루프

| 루프 | 주기 | 행동 | 결과 |
|---|---|---|---|
| 스와이프 | 3초 (배터리 1칸) | 알림 한 줄을 민다 | 합치기 → 폭발 → 연쇄 → 과부하 파동, P와 레벨 |
| 회차 | 수십 분~하루 | 앱 구매·강화·프로, 카드·판 강화, 덱 교체 | 티어 상승, 시너지, 레벨 해금 |
| 환생 | 하루~수일 | 공장 초기화, 백업 상점 | 평생 백업파일 보너스, 더 깊은 다음 회차 |
| (2차) | 수 주 | 클라우드 동기화 | 동기화 등급, 3갈래 트리 (계획) |

## 한 번의 스와이프

1. 배터리 확인(12칸, 3초 충전) → 민 줄 제거, 그 줄의 P(연쇄 ×1).
2. 뺀 자리 위아래에서 같은 앱이나 와일드처럼 합칠 수 있는 두 줄이 만나면 즉시 폭발한다. 빈자리를 중심으로 한 쌍씩 바깥으로 이어진다.
3. 폭발마다 연쇄 번호가 1 오른다. 튄더 두 줄은 2를 추가한다. 합체, 직접 폭발, 저티어 점화와 앱 효과가 게이지를 채운다.
4. 게이지가 100이고 대기 시간이 끝난 상태에서 폭발하면 과부하가 난다. 직전 파동의 수량에 기본 3을 곱해 다음 파동을 계산한다. 파동은 새 보드 줄을 미는 동작 없이 정산한다.
5. 스팸 문자는 폭발 쌍을 끊고 와일드는 한 번만 소모된다. 소모된 자리를 새 알림, 샌드위치, 장착 카드, 예약 줄이 채운다.

## 점수 파이프라인 (Balatro식 4단 표기)

내부 계산은 하나의 곱이지만, 화면에는 **4단계로 나눠 차례로 보여 준다**(사례조사 채택 7).

| 단계 | 이름 | 우리 항목 | 표시 색 |
|---|---|---|---|
| ① 기초 | 칩 | 수량 × 6^(티어−1) × 강화 레벨 × 마일스톤 배율 | 본문 |
| ② 덱 | 시너지 | 권역 · 카테고리 · 다양성 배율을 곱하고 ×4 상한을 적용 | 포인트(블루/앰버) |
| ③ 가치 | 보유 효과 | 프로 ×2 · 백업 강화 · 누적 처리량 자릿수 · 프리미엄 ★ · 앱 효과 | 연쇄 색(오렌지/골드) |
| ④ 연쇄 | 폭발 | 일반 (1+n), 강화 때 연쇄당 증가폭 확대 · 과부하 파동 수량 3ⁿ · 과열 P 상한 | 연쇄 색 대형 |

## 직접 플레이 vs 자동

| | 직접 | 자동 정리 |
|---|---|---|
| 간격 | 배터리 3초 | 4.5초 (백업·클라우드 등으로 단축, 최종 하한 0.5초) |
| 판단 | 판 전체를 본다 | 합치기 나는 가장 아래 줄 → 카드 → 스팸 문자 → 맨 아래 (백업 5단계부터 한 수 앞) |
| 행동 차이 | 메모를 직접 밀면 해당 줄 가치 ×2 | 엔진이 찾은 줄을 정리. 앱 효과 정산 후 스와이프 P ×0.6 |
| 오프라인 | — | 최근 분당 수입 × 자동 속도 비중 40% × 계정별 효율 × 인정 분. 기본 상한 8·10·12시간과 상점 강화 |

## 상태와 결정론

- `GameState` 하나가 저장 단위. 시간은 입력(`now`)으로만, 난수는 SplitMix64 한 개의 `Long`.
- 같은 상태 + 같은 입력 = 같은 결과. 일일 도전과 서버 재현은 이 성질을 쓴다.
- 결과는 박자 목록(`밀기 · 합치기 · 폭발 · 파동 · 등장 · 무료 강화 · 레벨업`)으로 나오고, 화면은 재생만 한다.
