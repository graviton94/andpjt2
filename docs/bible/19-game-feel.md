# 19 · 타격감 · FX (손맛)

이 장르의 재미 절반은 **숫자가 터지는 순간의 손맛**이다. 발라트로(점수 칩 × 배율이 불붙으며 쌓이는 연출), 뱀서(화면을 덮는 과잉 이펙트와 연쇄 폭발)처럼 **작은 행동 → 과장된 반응**, **연쇄가 길수록 한 단계씩 더 미쳐 가는 확대**를 목표로 한다.

참고: [pixelfx](https://github.com/patch-gg/pixelfx) (MIT)의 **구조**(데이터 이펙트, 두 겹 합성, 팔레트 램프, 타격 안무 표, 품질 기준)를 가져온다. 파일은 복사하지 않고 Kotlin으로 새로 쓴다. 그림체(픽셀아트)는 따르지 않는다(우리는 글래스·네온). 크레딧에 "FX 구조 inspired by pixelfx" 표기.

**시연판**: [타격감 시연](https://claude.ai/artifact/5zuf2fwBU2HxaW84wsY2WS) (소스 `docs/design/fx-demo/`). 1·3·5·8·12연쇄, 과부하 파동, 과열 보호 도장, 움직임 줄이기, 소리를 직접 눌러 본다.

## 1. 원칙

| 원칙 | 기준 |
|---|---|
| 빠른 공격, 느린 잔향 | 반응은 첫 프레임에(≤16ms), 잔광·파편은 0.3~0.8초, 큰 연출은 2~4초 |
| 확대의 사다리 | 연쇄·과부하·티어가 오를수록 **한 칸씩** 커진다. 처음부터 최대치를 쓰지 않는다 |
| 빛이 뜨거움을 말한다 | 큰 빛 웅덩이 + 작은 뜨거운 핵. 평면 채우기 대신 선과 빛 |
| 앱마다 다른 불꽃 | 파편·불꽃 색은 그 앱 아이콘의 브랜드색 램프. 60종이 자동으로 다르게 터진다 |
| 숫자가 주인공 | 점수는 날아가고, 커지고, 쌓이고, 지갑으로 빨려 들어간다 |
| 판을 가리지 않는다 | 다음 스와이프 대상이 보이는 시간 ≥ 70%. 큰 연출 중에도 입력 받음(연출은 빨리감기) |
| 설정으로 끈다 | 움직임 줄이기: 셰이크 0, 파편 30%, 번쩍임 없음. 저사양: 파편 예산 절반, 블러 대체 |

## 2. 엔진과의 연결 (박자 → 연출)

엔진은 이미 스와이프 결과를 **박자(Beat) 목록**으로 낸다(`SwipeOutcome.beats`). FX 감독(FxDirector)이 박자를 시간표로 바꿔 재생한다. 판정은 끝나 있고 연출은 재생만 한다(되돌릴 일 없음).

| 박자 | 연출 | 소리 · 햅틱 |
|---|---|---|
| `Swiped` | 카드가 손가락 방향으로 휙(110ms) + 잔상 2장, 빈자리로 위아래 카드가 스프링 당김 | 스와이프 휙, 약한 틱 |
| `Merged` | 두 카드가 부딪혀 1.06배 팝(140ms), 맞닿은 선에 빛 줄, 개수 점(●○) 채워짐 | 착 붙는 소리, 틱 |
| `Burst` | **히트스톱** 후 카드가 알림 파편으로 산산조각(앱 브랜드색), 빛 웅덩이, 점수 숫자 튀어오름 | 연쇄 번호마다 반음씩 높아지는 팡(최대 +4반음), 단계별 진동 |
| `Wave` (과부하 파동) | 판 전체를 가로지르는 빛의 띠, 숨은 알림 수(×3ⁿ)가 계기판처럼 치솟음, 화면 가장자리 불꽃 | 우르르 + 파동마다 쿵 |
| `LevelUp` | 상태표시줄 레벨 칩이 터지며 새 해금 카드가 미끄러져 들어옴 | 상승 아르페지오 |
| `Capped` (과열 보호) | 증기 분출 + "과열 보호" 도장 쾅. 손해가 아니라 "너무 세서 넘쳤다"는 자랑 | 쉭 + 도장 |
| `FreeUpgrade` | 해당 앱 아이콘에 위 화살표 반짝 | 짧은 띠링 |
| 고유 효과 발동 | 효과 아이콘 배지가 카드 옆에서 반짝(예: 너튜브 연쇄 +1, 로빈훗훗 ×2.4 도박 숫자) | 효과별 짧은 음 |

## 3. 확대의 사다리 (연쇄 단계)

| 연쇄 | 이름 | 히트스톱 | 흔들림(카드 영역) | 파편 | 화면 | 숫자 |
|---|---|---|---|---|---|---|
| 1 | 팡 | 28ms | 1.5dp | 12개 | — | 작게 튐 |
| 2~3 | 연쇄 | 36ms | 2dp | 20개/폭발 | 가장자리 살짝 밝아짐 | "2연쇄!" 문구 |
| 4~5 | 폭주 | 48ms | 2.5dp | 32개 + 불씨 | 배경 블롭 색이 주황으로 | 문구 커짐, 숫자 회전 등장 |
| 6~8 | 대폭주 | 60ms | 3dp | 48개 + 고리 충격파 | 화면 가장자리 불꽃 테두리 | 배율 칸(×) 불붙음 (발라트로식) |
| 9+ | 알림 해일 | 80ms + 슬로모 200ms | 3dp + 줌 펀치 1.03 | 예산 상한까지 | 판 전체 섬광 + 색수차 한 번 | 숫자가 화면 가운데로 모였다 지갑으로 빨려 감 |
| 과부하 | 파동 n | 파동마다 40ms | 파동마다 커짐 | 판 아래로 쏟아지는 알림 비 | 빛의 띠가 위→아래 | 숨은 알림 계기판 |

화면 전체 셰이크는 쓰지 않는다(토큰 `shakeScreenDp: 0`). 흔들림은 카드 영역만.

## 4. 숫자 연출 (점수가 주인공)

1. 폭발 자리에서 **기본 점수**가 튀어오른다(가치 × 개수).
2. 연쇄 번호 칸 **×(1+n)**이 옆에 붙으며 불꽃(발라트로의 배율 칸).
3. 시너지·고유 효과 배지가 차례로 **×1.22**, **×2** 식으로 붙을 때마다 숫자가 한 번씩 부풀어 오른다(각 85ms, 박자 토큰 `chainStep`).
4. **합계 공개 (발라트로식)**: 연쇄가 끝나면 칩·배율 상자가 합쳐지고, 판이 어두워지며 가운데에 `칩 × 배율` 식과 **합계 숫자가 0부터 촤르륵 카운트업**(620ms, 코인 틱 피치 상승) → 끝에서 **쾅**(스프링 펀치, 불꽃 왕관, 별·스파크·고리, 붐 + 화음). 이번 회차 최고면 "최고 기록!". 그 뒤 곡선 궤적으로 지갑에 꽂히고 지갑 카운트업(360ms, 큰 수 650ms).
   - 폭발마다 카드 위에 **파란 +칩 숫자**와 **빨간 +1 배율**이 크게 튄다(펑펑). 흩어지는 숫자는 '적립'이고, 가운데 합계가 '정산'이다.
5. 큰 단위가 바뀌는 순간(M → B → T)에는 단위 글자가 따로 쿵 하고 바뀐다("1B 돌파!").

## 5. 파편·빛 시스템 (pixelfx 구조를 Kotlin으로)

| 요소 | 설계 |
|---|---|
| 파티클 종류 | `SHRED`(알림 파편: 둥근 사각 조각, 회전·감속·페이드), `SPARK`(속도 방향으로 늘어나는 선, 빛 레이어), `MOTE`(떠오르는 빛 알갱이), `VAPOUR`(과열 증기, 부풀며 옅어짐), `STAR`(반짝 4점), `RING`(충격파 고리, 기울어진 원판 앞·뒤 반쪽) |
| 시뮬레이션 | 고정 스텝 120Hz, `withFrameNanos` 시간 누적. 시드 난수(스와이프 번호 + 행 id)라 같은 스와이프는 늘 같은 모양(리플레이·영상 캡처에 유리) |
| 두 겹 합성 | 색 레이어(일반 알파) → 카드 → 빛 레이어(`BlendMode.Plus`). 뜨거운 것은 빛 레이어에 |
| 팔레트 램프 | 앱마다 4~6색 램프(아이콘 브랜드색 → 밝은 쪽은 흰색, 어두운 쪽은 배경색). 고유 효과·티어가 높을수록 램프 끝이 금색으로 |
| 풀링 | 파티클 고정 풀 600개(저사양 300). 넘치면 오래된 것부터 재사용 |
| 예산 | FX 그리기 프레임당 2ms 이하(Pixel 6a 기준), 저사양은 자동으로 파편 절반·빛 블러 대체 |
| 안무 데이터 | 박자 종류 × 연쇄 단계별 표(`docs/design/tokens.json`의 `fx`): 히트스톱, 흔들림, 밀림, 번쩍임, 파편 수, 소리 피치 |


### 5-1. 화면 왜곡 (후처리 셰이더) — 동그라미·색종이 대신

평면 위에 얹는 고리·색종이는 스티커처럼 보인다. 타격감은 **화면 자체가 휘는 것**에서 나온다. 판 전체를 한 장의 텍스처로 그린 뒤 셰이더 한 번으로 휜다.

| 효과 | 언제 | 구현 |
|---|---|---|
| 충격파 굴절 | 폭발마다(세기 = 연쇄 단계), 칩·배율 도착, 지갑 착지 | 퍼지는 고리 띠 안쪽은 당기고 바깥은 미는 렌즈 변위(가우스 띠 × 부호), 띠에 RGB 분리와 엷은 빛. 동시 8개 |
| 유리 깨짐 (카드) | 폭발마다 | 카드 이미지를 그대로 떠서 충격점 중심 **거미줄 조각**(방사선 9~11 × 동심 3겹)으로 자름. 70ms 금 간 선만 보인 뒤(히트스톱과 겹침) 조각이 회전하며 날아감, 조각마다 반사광 |
| 유리 깨짐 (화면) | 합계가 쾅 찍힐 때, 9연쇄 이상 폭발 | 로그-극좌표 보로노이 금이 충격점에서 0.15초에 퍼지고, 조각마다 살짝 다른 굴절 → 0.3초 뒤 조각이 아래로 흘러내리며 사라짐 |
| 열 아지랑이 | 열기(4연쇄 이상, 파동) | 사인 노이즈 UV 일렁임, 열기에 비례 |
| 과부하 물결 | 과부하 파동 | 위→아래로 지나가는 가로 물결 띠(UV 사인 변위 + RGB 분리) |
| RGB 분리 | 큰 타격 순간 | 화면 중심 기준 색 채널 어긋남, 빠르게 감쇠 |
| 젖빛 유리 카드 | 상시 | 움직이는 색 블롭 배경 + 저해상 사본(=블러) 위에 흰 막·윗면 하이라이트·1px 테두리. 깨질 때 유리 질감이 산다 |

**층 규칙** · 화면은 두 층이다. ① 세계 층(배경·장식·카드·파편·빛): 왜곡·깨짐·흔들림을 모두 받는다. ② **점수 층**(지갑, 칩×배율, 합계, +숫자, 문구): 항상 맨 위, **왜곡·깨짐을 받지 않는다**(흔들림만). 숫자는 어떤 연출에서도 읽혀야 한다.

**장식 붕괴** · 8연쇄 이상 또는 과부하 파동이 들어간 정산이 쾅 찍히면, 흉내 낸 폰 UI(상태표시줄 시간·신호·와이파이·배터리, Lv·덱 칩, 아래 '관리'·'모두 지우기', 홈 바)가 튕겨 올랐다가 중력으로 무너진다. 약 1초 뒤 하나씩 순서대로 스프링으로 제자리에 딸깍 돌아온다(조각마다 짧은 클릭음). 실제 조작 버튼(끌어내리는 패널 손잡이 등)은 붕괴 대상에서 뺀다.

**Android 구현**: `RuntimeShader`(AGSL, Android 13+)를 판 컨테이너의 `RenderEffect`로. 충격파·금·물결은 같은 uniform 배열(시연과 동일 수식). Android 12 이하는 셰이더 없이 카드 조각 깨짐 + 2D 연출만(성능 등급 '저'와 같은 경로). 움직임 줄이기: 왜곡 0, 조각 30%.

**시연 v1~v4 교훈** · 수치(파편 수·크기)를 키우는 건 효과가 없다. 차이를 만든 것은 순서대로 ① 적립→정산 구조(칩×배율→합계 쾅), ② 게임 글꼴의 단단한 외곽선, ③ 레이어 사운드, ④ **화면을 휘는 왜곡과 유리 깨짐**이다.

### 5-2. 이벤트 · 돌발 연출 (성격별)

판 연쇄와 같은 무게로 만든다. 점수 층 규칙(5-1)은 그대로.

| 이벤트 | 연출 순서 | 셰이더 · 소리 |
|---|---|---|
| **과열 보호** | 합계 쾅 → **달아오름**(0.75초: 숫자가 붉게 떨림, 노랑·검정 경고 테이프 흐름, 온도계 상승, 화면 붉은 막·가장자리 경보, 불씨) → **끓어 넘침**(녹은 방울이 숫자 위로 튐) → **증기 배출**(양옆에서 증기 분사, 얼음색 섬광, 열 0) → 숫자가 넘친 만큼 줄어드는 카운트다운, 원래 값은 빨간 줄로 지움 → **도장 쾅**(이중 테두리, 잉크 튐) | 아지랑이 최대, 붉은 틴트 → 파란 틴트 / 빨라지는 경고음, 끓는 소리, 긴 증기 쉭, 도장 쿵 |
| **알림 훈련** (재난 문자 연타) | 사이렌 + 붉은 경보 비네트 맥동 + 경보 배너가 위에서 떨어짐(타이머 막대) → 탭마다 그 자리에 충격파·불꽃·"+1%", 큰 배율 숫자가 펀치, 10연타마다 이정표 → **최대 ×2**: 화면 유리 깨짐 + 장식 붕괴 | 2음 사이렌, 탭마다 5음계로 오르는 삑, 이정표 화음 |
| **앱 충돌** | 화면이 가로로 찢어지는 글리치(블록 어긋남·RGB) + 채도 빠짐 → "○○이(가) 중지됨" 대화상자 → 탭: **CRT 꺼짐**(가로 한 줄 → 점) → 켜짐 + 부팅 화음, "재시작! 수입 +30%" | 글리치 노이즈, 전원 하강음, 부팅 아르페지오 |
| **스팸 전화** | 가짜 수신 화면이 아래에서 올라옴, 벨소리 박자에 맞춰 폰 전체가 진동, "자동 정리 멈춤" → 탭(차단): **수신 화면 유리가 산산조각** + 화면 금 + "차단!" | 트릴 벨, 유리 깨짐 |
| **배터리 부족** | 화면 채도·밝기가 빠짐, 심장박동 쿵쿵, 배터리 아이콘 빨강 점멸 → 탭(충전): **번개**가 배터리에서 판으로 내리꽂힘, 섬광, 채도 과충전 후 복귀, 화면 가장자리 전기 스파크 | 심장박동, 전기 지직 + 상승음 |
| **복권** | 슬롯 릴이 감속하며 숫자 회전 → 당첨: 금빛 비 + 유리 깨짐 + 장식 붕괴 + 잭팟 화음 / 꽝: 상자가 쪼그라들고 잿빛, 연기, 슬픈 트롬본 | 릴 틱, 잭팟 / 실패 |
| **방해 금지** | 밤 파란 틴트, 초승달, 시간 느려짐, 잔잔한 패드음, 카드가 하나씩 조용히 정리되며 빛 알갱이 | 패드 화음, 부드러운 쉭 |

**Android 구현** · 같은 후처리 셰이더에 uniform 5개 추가: `glitch`(가로 찢김), `crt`(화면 꺼짐/켜짐), `sat`·`bright`(채도·밝기), `tint`(색 막), `alarm`(가장자리 경보). 움직임 줄이기: 글리치 0, 경보 40%, 흔들림 0.

## 7. 시연 v1 → v2 교훈

v1은 사다리 수치만 키웠고 "구리다"는 평을 받았다. 원인과 v2 처방:

| 원인 (v1) | 처방 (v2, 본 게임 기준) |
|---|---|
| 숫자가 쌓이지 않고 흩어짐("+84.0만"이 여기저기 떠서 사라짐) | **칩 × 배율 점수판**: 폭발마다 빛 구슬이 값을 칩 상자로 실어 나르고, 배율 상자는 연쇄 번호로 오른다. 시너지·과부하는 배율에 붙는다. 연쇄가 끝나면 두 상자가 합쳐져 합계가 쾅 → 지갑으로 날아가 카운트업 → 단위가 바뀌면 단위 글자만 따로 쿵("억 돌파!") |
| 본문 글꼴, 반투명 회색 외곽선, 정지한 글자 | 디스플레이 글꼴(Black Han Sans 계열) + **단단한 잉크 외곽선 + 딱딱한 그림자 + 세로 그라데이션**, 글자마다 튀어나옴(백아웃)과 미세한 출렁임. 숫자에서 ".0" 제거 |
| 단일 오실레이터 삑 | 레이어 합성: 종이 찢김(노이즈) + 몸통 쿵(사인 피치 하강) + 연쇄마다 **5음계로 오르는** 플럭, 칩 틱, 배율 둔-, 정산 붐 + 아르페지오, 지갑 코인 틱(피치 상승), 짧은 에코 + 컴프레서 |
| 화면 전체 따뜻한 막 + 가산 합성으로 판이 베이지로 씻김 | 판은 어둡고 선명하게 유지, 가산은 작은 뜨거운 것(불꽃·핵·구슬)만, 열기는 화면 가장자리에만 |
| 카드가 그냥 사라짐 | 터지기 직전 흰 충전 + 1.06배 부풂(50ms) → 카드가 세로 조각 5개로 찢어지고 아이콘이 따로 튕겨 나감, 새 카드는 스프링으로 내려앉음 |
