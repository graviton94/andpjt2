# 알림 청소부 경제 v0.3 · 한 달 넘게 가는 성장

Android 게임 설계 · 2026-11-23 · [경제 v0.2](economy-v0.2.md)를 장기 플레이 기준으로 다시 잡음

**결론** · 레벨을 "이번 회차 누적 P"의 지수 함수로 바꾸고, 환생(공장 초기화) 이득이 회차마다 쌓이게 했다. 하루 1시간 직접 플레이와 오프라인 수입을 가정한 8주 시뮬레이션에서 다음과 같이 나왔다.

| 지표 | 결과 |
|---|---|
| 첫 공장 초기화 | 1일차 |
| 5티어 | 1주차 |
| 환생 없이 30일 | Lv34에서 멈춤, 5티어 없음 |
| 마지막 앱(Lv88) | 8주 안에 시드 4개 중 1개만 도달(52일차) |

해금은 첫 열흘 동안 매우 촘촘하지만, **열흘 이후에는 해금 사이가 최대 26일까지 벌어진다.** 그 구간을 채울 해금표를 7장에 제안한다.

```sh
./gradlew -p tools/economy-sim run --args="daily 56 4"   # 56일, 시드 4개 (약 1분)
```

## 1. 왜 바꿨나

v0.2는 첫 초기화가 2.9시간, 3회차부터는 가속이 멈췄다. 장르 기준으로 너무 짧고 환생의 손맛이 약했다. 레벨이 스와이프 XP로만 올라서 환생으로 산 배율이 레벨 진행을 앞당기지 못한 것이 근본 원인이었다.

## 2. 바꾼 규칙

| 항목 | v0.2 | **v0.3** |
|---|---|---|
| 레벨 | XP (스와이프·폭발 티어) | **이번 회차 누적 P.** Lv L에 필요한 P = 30 × 2.5^(L−2). Lv25부터 배수가 레벨마다 +0.005 (Lv50 ×2.63, Lv88 ×2.82) |
| 빠른 부팅 (백업) | XP +25% | 레벨 기준 P −10% (곱) |
| 백업파일 | ∛(P÷10⁹) + 레벨 항 | **⌊10 × ∛(P ÷ 10¹²)⌋ + (레벨 − 20)** |
| 환생 누적 이득 | 없음 | **지금까지 얻은 백업파일 1개마다 모든 알림 가치 +5%** (쓴 것도 포함) |
| 알림 가치 ×1.1 (백업) | 가격 성장 ×1.35 | ×1.15 |
| 백업 상점 | 처음부터 전부 | **초기화 횟수로 단계 해금**: 1회 가치·빠른 부팅·시작 자금·오프라인 / 2회 샌드위치·연쇄 / 3회 자동·시너지 / 4회 마일스톤·기억된 앱 / 5회 배터리 / 6회 과부하 / 8회 앱 슬롯 / 10회 알림창 / 12회 와일드 / 15회 이벤트 슬롯 |
| 오프라인 정산 | 없음 | **최근 수입 속도 × 10%**, 상한 1시간 (Lv20 2시간, Lv40 4시간), 백업 "오프라인"이 단계마다 +5%p · +1시간 |
| 앱 해금 레벨 | 1~50 | **1~88**: 2티어 3·4·6·8 · 3티어 10·12·14·17 · 4티어 20·23·26·29 · 5티어 36·42·48·55 · 6티어 64·72·80·88 |

**버그 수정** · 백업 상점의 "배터리"로 최대치가 늘면 충전 예약이 걸리지 않아, 배터리가 0에서 멈추는 문제가 있었다. 엔진을 고치고 회귀 테스트를 붙였다. 시뮬레이션이 특정 설정에서 갑자기 정체되던 원인이 이 버그였다.

## 3. 시뮬레이션 모델

- 하루 4번 × 15분 직접 플레이(한 수 앞을 보는 플레이어). 접속 사이 4시간과 밤은 오프라인 정산.
- 지출은 v0.2와 같은 탐욕 규칙, 덱은 시너지 우선.
- 초기화는 "초기화하면 평생 백업파일 보너스가 60% 이상 오를 때" 또는 "세 번 접속하는 동안 레벨이 안 오를 때".

**성장 곡선의 모양** · 1~2주차에 환생 이득이 빠르게 쌓여 Lv34 → 69로 뛰고, 이후 레벨 기준 배수가 커지면서 주당 2~3레벨로 느려진다. 2주차의 급등은 "환생이 통했다"는 큰 순간이라 유지할 가치가 있다. 대신 3~8주차는 레벨이 천천히 오르므로, **레벨이 아닌 다른 해금이 그 구간을 채워야 한다.**

## 5. 해금 밀도

| 기간 | 해금 | 문제 |
|---|---|---|
| 0~1일 | 앱 12개, 카드 3장, 판 강화 4종, 덱·이벤트 슬롯, 공장 초기화 | 첫날에 너무 몰림 |
| 1~10일 | 앱 6개, 덱 슬롯, 백업 상점 15항목 (초기화마다 1~2개) | 적당 |
| 10~56일 | 시드 1 기준 앱 2개 (13일 장마감 · 22일 댓글폭탄). 회의록봇은 8주 안에 못 감 | **해금 사이 최대 26일** |

직접 플레이 시간 기준 해금 간격은 중앙값 90초, 90번째 백분위 1시간이다. 문제는 달력 기준 후반 공백이다.

## 6. 남은 문제

1. **6티어가 이르다(11.5일).** 5티어와 6티어 사이 레벨 간격을 넓히거나 6티어 앱 가격을 올린다.
2. **첫날 해금 과밀.** 판 강화·카드·덱 슬롯 일부를 2~5일차로 옮긴다(7장 표).
3. **후반 공백.** 7장의 신규 해금 콘텐츠가 필요하다. 엔진에는 아직 없다.
4. **회차 길이.** 2주차 이후 매일 초기화한다. 하루 한 번 "아침에 초기화, 저녁에 기록 경신"은 장르상 자연스럽지만, 회차가 길어지는 후반 구간도 있어야 한다(2차 환생).
5. 고유 효과 v3.1, 시간형 카드, 유료 부스트가 들어가면 다시 잰다.

## 7. 촘촘한 해금표 제안 (Lv1~90 + 초기화 횟수)

원칙: **모든 레벨에 해금 하나 이상**, 그리고 **초기화할 때마다 새 백업 항목이나 기능 하나 이상**. 레벨 해금은 매 회차 다시 밟으므로, 처음 열리는 것과 매번 다시 열리는 것을 구분해 보여 준다(처음 열면 강조, 이후엔 조용히).
