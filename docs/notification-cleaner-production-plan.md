# 알림 청소부 추가 개발계획서

Android 제품 기획 · v1.0 · 2026-11-22

**게임 한 줄 소개** · 방금 배달 알림 하나를 밀었는데, 단톡방과 메일이 연달아 터지고 배터리 아이콘까지 튕겨 나간다. 화면이 복구될 때쯤 점수는 방금 전보다 여러 자리 커져 있다.

**최종 목표** · 익숙한 스마트폰 알림창을 한 손으로 무너뜨리는 무한 증분 게임. 첫 10초에 조작과 폭발의 인과관계를 보여 주고, 5분 안에 같은 스와이프가 훨씬 큰 결과를 만드는 이유를 체감하게 한다. 사용자는 계속 스와이프하거나 자동 정리를 켠 채 숫자가 불어나는 모습을 볼 수 있다.

이 문서는 본편의 기준이다. 저장소의 《알림 청소부 FX》는 손맛·화면·연쇄를 보여 주는 **시연 앱**이다. 7연쇄, 14,967개 처리, 117,645 P는 시연판 첫 행동의 재현값이다. 본편의 밸런스는 아래 검증 기준으로 잡는다.

## 1. 같은 게임을 보는 세 관점

| 관점 | 가장 중요한 약속 | 판단 기준 |
|---|---|---|
| 총괄 PM | 소개 문구 없이도 한 손가락과 한 번의 폭발로 게임을 설명할 수 있다 | 6초 영상만 보고 처음 보는 사람이 어떤 입력이 폭발을 만들었는지 말한다 |
| 시니어 Android 개발자 | 하나의 판정이 게임 상태를 확정하고 화면·소리·진동은 그 결과를 재생한다 | 같은 입력에서 점수는 재현되고, 중간에 앱을 닫거나 연출을 건너뛰어도 보상이 정확하다 |
| 모바일 손맛에 민감한 플레이어 | 지울 때 찰칵, 붙을 때 쿵, 터질 때 내가 밀지 않은 나머지 화면까지 박살 난다 | 첫 폭발 뒤 손이 한 번 더 가거나 자동을 켜고 다음 폭발을 지켜본다 |

플레이어가 기억할 차별점은 **게임이 커질수록 알림창의 더 넓은 부분을 터뜨린다**는 것이다. 1연쇄에서는 카드 한 줄이 튀고, 과부하에서는 위쪽 빠른 설정과 상태 아이콘까지 순서대로 맞는다. 붕괴 직후 같은 알림창이 복구되면서 훨씬 두꺼운 새 알림 묶음이 내려온다. 게임을 잠시 접었다 켜면 쌓인 알림 한 묶음이 먼저 눈에 들어온다.

## 2. 첫 3분과 오래 남는 루프

| 시점 | 화면과 행동 | 의도 |
|---|---|---|
| 첫 0~10초 | 알림 7줄. 중앙 배송 알림과 그 양옆 단톡 알림만 강조한다. 배송 알림을 밀면 단톡·메일·일정 순서로 터지고 첫 과부하가 터진다 | 작은 입력과 큰 결과를 한 화면에서 연결 |
| 10~40초 | 줄의 숫자가 합쳐지는 순간을 한 번 보여 준다. 두 번째 과부하는 플레이어가 아무 줄이나 계속 밀어도 도달할 수 있게 빈칸의 보충 배열을 조정한다 | 규칙을 못 읽어도 폭발하고, 읽으면 한두 번 앞당김 |
| 40~90초 | 첫 앱 구매 또는 첫 강화가 열린다. 구매한 앱은 다음 일반 보충 슬롯 중 3번째 안에 들어온다. 해당 앱의 다음 폭발 때 달라진 배수를 한 번 표시한다 | 보상이 창고에만 쌓이지 않고 화면에 돌아옴 |
| 90~180초 | 자동 정리가 주기적으로 스와이프하고, 직접 밀어서 개입할 수 있다. 첫 짧은 돌발 알림은 목록 안으로 들어온다 | 손을 놓아도 다음 점화가 기대됨 |
| 다음 접속 | 충전과 제한된 오프라인 XP를 정산하고 그동안 쌓인 알림을 한 묶음으로 추가한다. 기존 앱 강화·기록과 끊어진 배열을 이어서 보여 준다 | 복귀 직후 실제 배열에서 한 번 더 스와이프할 이유를 줌 |

진행은 경험치로 자동 상승한다. 레벨이 오르면 앱이 순환에 추가되고, 새 한 줄에 더 많은 알림이 담기며, 과부하 파동 깊이가 커진다. 화면 전환이나 결제 없이 같은 알림창에서 이어진다. 유저가 직접 하는 영구 선택은 앱 구매와 앱별 강화다. 보유 앱의 배치와 권역×카테고리는 엔진이 자동으로 계산한다.

### 대표 장면 · 상태표시줄까지 올라가는 폭발

`배송 행 밀기 → 맞닿은 단톡 두 줄 합쳐짐 → 횟수 임계치에 도달 → 양옆이 비면서 메일과 일정 연쇄 → 대기 중이던 알림까지 과부하 → 시계·배터리·빠른 설정이 차례로 밀림 → 균열과 큰 점수 → 새 알림이 위에서 쏟아짐`

큰 결과에서 첫 시선은 연쇄 수, 다음 시선은 총 처리량, 마지막 시선은 점수·갱신이다. 이유는 한 번에 하나만 표시한다. 예를 들면 `메일 강화 ×1.60`, `국내권 ×1.25 · 소통 ×1.40`, `신기록`이 해당 순간에만 뜬다. 계산 상세와 정확한 정수는 기록에서 연다.

## 3. 연쇄, 증분 시너지와 경제

### 판정 계약

1. 가로 스와이프 임계치를 넘어 놓으면 행동력 1을 소비한다. 같은 앱 ID가 빈자리에서 맞닿으면 두 수량을 합친다. 수량이 기존 행 중 더 낮은 임계치에 도달하면 그 자리에서 폭발하고 새 이웃을 확인한다.
2. 큐에 남은 알림이 위에서 보충된다. 같은 앱 사이에 다른 한 줄이 낄 가능성을 의도적으로 높인다. 앱 수를 늘려도 무연쇄가 오래 이어지지 않도록 출현 가중치, 최근 연쇄 기록, 동일한 난수 시드로 시험한다.
3. 행동력과 별개의 과부하 게이지는 확정 스와이프와 실물 폭발로 충전한다. 초기 가설은 스와이프당 +21, 실물 폭발당 +11, 실물 3연쇄 또는 게이지 100% 상태의 첫 폭발에서 방출이다. 게이지가 찬 상태에서 폭발할 경로를 한 번의 보충으로 제공한다.
4. 방출 시 이번에 터진 앱들이 대기열의 여러 파동을 연다. 첫 파동의 시드는 해당 실물 폭발들의 총 처리량이다. 이후 `새 파동 = 직전 파동 × 현재 파동 배수`로 계산한다. 초기 배수 후보는 ×3, ×5, ×7, ×9. 실물과 대기열 모두 처리량과 점수에 반영한다.
5. 후반에는 여러 파동을 한 번의 충격으로 묶어 재생한다. 실측 연쇄 수와 처리량은 전부 집계한다. 화면에 보여 주는 충돌 박자는 9개 안팎을 시작값으로 검증한다. 기록에는 예를 들어 `132연쇄 · 9회 충격으로 표시`처럼 장면에서 생략된 파동을 확인할 수 있게 한다.

### 계층별 숫자

| 숫자 | 늘어나는 원인 | 사용처 |
|---|---|---|
| 처리량 | 행에 담긴 수량과 과부하 파동의 기하급수 증가 | 가까이 붙는 카드에서 대기열 전체로 파급이 커졌음을 시각화 |
| 점수 | 실제 처리량과 스와이프 안의 파동 순번, 앱·권역·카테고리·이벤트 배율 | 한 번의 최고점, 신기록, 공유 카드 |
| XP | 확정 행동, 실물 폭발과 유효한 파동, 제한된 방치 정산 | 지속 레벨과 새 앱·이벤트 해금 |
| 정리 포인트 P | 플레이 보상. 첫 폭발 깊이와 점수 자릿수에 맞춰 완만하게 증가 | 앱 구매와 강화 |
| 행동력 | 최초 12회와 시간 충전, 복귀 정산 | 확정 수동·자동 스와이프. 시연판의 3초당 1회와 자동 최소 3.2초를 비교 기준으로 사용 |

**스와이프 점수 공식 가안**

```text
앱별 기본값 = 같은 앱이 처리한 각 파동의 수량 × (실제 순번 + 1)을 더한 값
앱별 점수   = floor((앱별 기본값 × 앱 강화 배율 + 그 앱의 고유 가산점)
                    × 가상 사용자권역 배율 × 앱 카테고리 배율 × 이벤트 배율)
총점        = 처음 밀어낸 행의 처리량 + 모든 앱별 점수의 합
```

앱 고유 가산은 해당 스와이프에 그 앱이 여러 번 터져도 한 번이다. 판정 시각의 앱 레벨·권역·카테고리·이벤트 배율을 끝까지 사용한다. 지역과 카테고리 성장에 이번 처리량을 더해 다음 스와이프에 반영한다. 권역은 카탈로그상의 가상 시장이다.

**계산 예시** · 같은 앱의 기본값이 752, 강화 ×1.60, 고유값 +12, 권역 ×1.25, 카테고리 ×1.40, 이벤트 ×1.30이면 앱 점수는 2,764다. 밀어낸 행이 1개라면 총점은 2,765다. 조, 경, 해 이후에도 정밀도는 저장과 판정에서 유지한다.

**경제 분리 가설** · 본편의 P는 점수만큼 빠르게 팽창하면 첫날에 강화 목표가 사라진다. 첫 실험에서는 `8 + 3 × (점수 자릿수 − 1)² + 5 × floor(√연쇄 수)`를 출발점으로 하고, 상점 첫 구매를 40~90초, 첫날 두 번째 강화 체감을 목표로 가격을 맞춘다. 예를 들어 2,765점과 3연쇄는 40 P이며, 선택형 두 배 보상까지 받으면 80 P다. 이 수치와 가격표는 경제 시뮬레이터에서 먼저 바꾼다. XP는 점수의 수치 대신 유효 행동과 연쇄 깊이를 사용한다.

### 성장 곡선의 시작값

- 새 알림의 무게는 플레이어 레벨 3단계마다 ×3으로 가정한다. 새 보충의 수량을 `[1, 2, 2, 3] × 무게`, 폭발 임계치를 `4 × 무게`에서 시작한다. 이미 도착한 행의 수량과 임계치는 저장된 값으로 계산한다.
- 앱 강화는 시작 배율 ×1.00에 단계당 ×1.60을 검증한다. 초반 P 가격은 75, 150, 300을 후보로 두고 시드 30개 이상에서 첫 구매와 첫 세 번의 강화 템포를 비교한다. 시연판의 가격·직접 P 환산은 비교 기준으로 남긴다.
- 과부하는 레벨이 오를수록 깊어지고, 일반 알림과 실물 폭발 사이에 분기되는 패턴을 추가한다. 5분 동안 과부하가 지속적으로 나타나되 매 스와이프가 같은 강도로 보이는지는 별도로 측정한다.

### 앱·권역·카테고리

- 기본 앱 4종과 지급·구매 앱 4종으로 시작한다. 앱 카드에는 카테고리, 가상 사용자권역, 현재 강화 배율, 해당 앱 고유 효과 한 줄이 있다.
- 앱을 강화할 때는 `직전 배율 → 앞으로 이 앱이 터질 때의 배율`을 한 행에서 비교한다. 최초 몇 번의 효과가 이해될 때까지 상점은 하단 고정 버튼으로 유지한다.
- 권역과 카테고리는 처리량에 따라 각각 성장한다. 로그 또는 자릿수 기반 단계를 써서 과부하 한 번이 두 배율을 동시에 무한정 밀어 올리는 루프를 제어한다. 숫자가 폭주하는 구간은 파동 곱에서 만들고, 영구 배율은 플레이의 이력으로 남긴다.
- 예시 앱 **톡탁톡** · 국내권×소통, 첫 단톡 연쇄에서 고유값 한 번. **메일소포** · 글로벌×소통, 큰 묶음이 터질 때 고유값이 드러난다. 이름과 아이콘 발주에는 풍자할 알림 습관, 실루엣, 작은 화면에서의 구분 기준을 적는다.

## 4. 반복을 바꾸는 기능과 수익 모델

| 기능 | 실제 플레이 변화 | 첫 구현 범위 |
|---|---|---|
| 자동 정리 | 충전량을 유지하며 현재 보드에서 유효한 큰 연쇄를 찾는다. 수동 입력은 자동 예약에 우선한다 | 시연판 알고리즘을 기준으로 80회 이상 돌리고 최장 무폭발 구간을 기록 |
| 스팸 | 놔두면 복제되고, 정확히 밀면 양옆에 있던 같은 앱을 강제 연결할 기회가 생긴다 | 목록 안의 한 행, 짧은 안내와 두 번째 복제 알림 |
| 전화 | 자동을 잠깐 멈추고 응답·스와이프 중 하나로 종료한다 | 놓쳐도 자동 복귀. 실제 전화나 마이크 권한은 사용하지 않음 |
| 60초 알림훈련 | 연타로 이벤트 배율이 오른다. 이벤트 배율을 어느 스와이프가 받았는지 결과에 표시한다 | 화면 하단 작은 패널과 쉬운 탭 동작. 탭당 +0.01, ×2.00을 가안으로 시작 |
| 붕괴 공유 카드 | 성공 순간의 한 프레임과 연쇄·처리량·점수를 묶어 Android 공유 시트에서 보낸다 | 세로 이미지 한 규격을 먼저 제작. 점수는 확정된 세션 데이터에서 생성 |
| 일일 기록 | 모두가 동일한 시드·앱·배율·행동력으로 최고 스와이프 기록을 비교한다 | 로컬 일일 기록 먼저. 공개 순위는 서버 재현 판정이 완성된 뒤 연결 |

**광고** · 큰 연쇄가 완전히 끝나고 선택형 버튼이 보인다. 기본 P는 이미 지급된 상태이며, 자격이 있는 연쇄의 P를 완료 리워드 콜백으로 한 번 더 지급한다. 광고 거래 ID가 동일하면 재시도와 복귀에서 한 번만 정산한다. 점수, XP와 일일 기록은 판정값을 유지한다.

**결제** · 우선 후보는 알림창 테마, 파쇄 효과, 진동·효과음 프리셋, 개별 꾸미기다. 자유 플레이의 강화 편의나 행동력 충전은 초기 퍼널의 경제가 검증된 뒤 검토한다. 모든 플레이 구간은 기본 무료이며 일일 기록의 규칙에는 구매 효과가 적용되지 않는다.

### 측정과 플레이테스트

- **코어 행동** · 첫 스와이프까지 걸린 시간, 첫 연쇄를 본 비율, 첫 연쇄 이후 30초 안에 다시 스와이프하거나 자동을 켠 비율을 기록한다. 초기 가설은 신규 10명 중 첫 10초 내 8명이 첫 스와이프, 연쇄 뒤 7명이 자발적으로 이어서 플레이하는 것이다.
- **손맛** · 실기기 화면·소리·손을 함께 촬영한다. 임계점 햅틱과 손을 뗀 뒤의 첫 화면 반응, 첫 충돌에서 두 번째로 가는 간격을 확인한다. 시작 목표는 손을 뗀 뒤 첫 시각 반응 p95 50ms 미만과 대표 60Hz 기기의 프레임 예산 16.7ms를 기준으로 한 프로파일링이다.
- **과부하 빈도** · 일반 스와이프와 큰 보상의 비율이 구별되면서 긴 무폭발 구간을 피한다. 5분 세션의 최고 점수 자릿수 변화와 연쇄 간격 p50·p90, 앱 강화 직후 체감 변화를 기록한다.
- **경제** · 첫 구매 시간, 행동력 0에 머무는 비율, 구매 직후 다시 상점을 열기까지 걸린 시간, 광고가 없을 때의 동일한 플레이 루프를 본다. 순위와 지갑 값이 별개라는 점은 10명 중 몇 명이 이해했는지 물어 확인한다.

모든 시간·성능·비율 기준은 기획 목표다. 에뮬레이터는 기능 회귀와 촬영을, 실제 보급형·중급형 Android는 입력 지연·프레임 시간·햅틱과 오디오 판단을 맡는다.
