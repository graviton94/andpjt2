### 2-1. IARC

- 카테고리: 게임 (캐주얼/퍼즐)
- 폭력·공포·성적·욕설·약물·술·담배·실제 돈 도박·모의 도박: 모두 **아니요**
  - 게임 속 '복권' 이벤트 카드는 **게임 재화(P)로만** 굴리고 돈을 걸거나 돈으로 살 수 없음 → 모의 도박 아님으로 설명. (보수적으로 가려면 출시 빌드에서 이름을 '행운 알림'으로 바꾸는 안 검토)
- 사용자 간 상호작용 / 콘텐츠 공유: **아니요** (채팅·친구·이름 입력 없음. 일일 도전 순위는 출시 후 추가 시 다시 답함)
- 위치 공유: 아니요
- 디지털 상품 구매: **예**
- 무작위 아이템 구매: **아니요** (확률형 없음, 모든 상품은 사기 전 내용 공개)
- 예상 결과: 전체이용가 / PEGI 3 / ESRB Everyone (+ 인앱 구매)

### 2-2. 데이터 보안 — CSV

1. `python3 make_data_safety_csv.py profile_notificationcleaner.json data_safety_import.csv` (이 폴더, 이미 생성됨)
2. 콘솔 → 데이터 보안 → 가져오기·내보내기 → **CSV 가져오기** → 미리보기 → 저장

판단 근거:
- 계정 생성 방법: **없음** (`PSL_ACM_NONE`). 사용자 ID·이름·이메일 수집 없음.
- 수집: 대략적 위치(광고 SDK) · 구매 내역(결제 이벤트 분석, 지급 확인) · 진단 · 비정상 종료 로그 · 앱 상호작용 · 기기 ID(광고 ID).
- 공유 ✔ 는 **AdMob·미디에이션 광고 네트워크로 가는 항목만**: 위치·진단·상호작용·기기 ID. Firebase는 우리 대신 처리하는 서비스 제공업체라 공유가 아님.
- 모두 필수(분석을 끌 수 없음), 임시 처리 아님, 전송 암호화 예, 삭제 요청 가능 예.

## 5. 앱 서명

로그인이 없어 Firebase·카카오 지문 등록은 필요 없다. 다만 Play 앱 서명 키 SHA-256을 기록해 두고(설정 → 앱 무결성), AdMob 앱 등록 시 패키지명 일치만 확인.

## 6. AdMob

앱 추가(미게시) → **보상형 광고 단위 8개**(지면별: best_double, offline_double, boost, overclock, warp, battery, data_box, free_upgrade — 지면별 eCPM·완료율을 따로 보려고) → ID는 GitHub 비밀값 → `app-ads.txt`를 Pages 루트에 → GDPR·US 주 개인정보 메시지(UMP) 만들기 → 미디에이션 그룹(AppLovin·Unity·Pangle).

## 7. 테스트 트랙

내부 테스트 → **비공개 테스트 12명 × 14일 연속** → 프로덕션 신청. 14일 동안 볼 지표: D1·D7, 첫 초기화 도달(목표 2일), 첫 결제까지 일수, 광고 시청 분포, 크래시·ANR, 결제 퍼널(`iap_view → iap_start → iap_success`), 프로필별 Lv124 속도(17장 시뮬과 비교).
