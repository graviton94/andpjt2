# 다른 세션에 전달할 EX 승인 검토 요청

방해 금지!의 유료 EX 꾸미기 도입을 독립적으로 검토해 주세요. 이번 요청의 산출물은 **구현 전 리뷰와 승인 권고**입니다. 제품 구현은 사용자 최종 결정 후 시작합니다.

저장소는 `graviton94/donotdisturb`, 검토 브랜치는 `ccr-balance-port`, 설계·시뮬레이션 기준 커밋은 `2a52ed8`입니다. 먼저 [구현 전 검토 보고서](ex-review-report.md)를 읽고, [아이템·세트 상세](cosmetics-proposal.md), [풀세트 시드별 CSV](cosmetic-ex-collection-seeds.csv), [기본 비교 결과](offline-pass-review.md), [시뮬레이터](../../tools/economy-sim/cosmetic-probe.py), [결정 기록](../bible/11-decision-log.md)을 확인해 주세요.

## 사용자가 직접 결정한 사항

1. 유료로만 살 수 있는 EX 꾸미기는 실제 게임 수입·점수에 혜택을 줍니다.
2. EX 효과는 소유량에 따라 누적합니다. 각 유료 아이템에 개별 효과가 있고, 세트를 완성하면 추가 효과를 줍니다. 많이 구매한 슈퍼유저에게 구매량에 상응하는 이득을 주는 것이 목적입니다.
3. P2W는 사용자가 정한 프로젝트 방향입니다. 위 요구는 유저 만족을 위해 사용자가 추가한 기획입니다.

사용자 원문입니다.

> 아니 EX는 누적으로, 유료에셋 많이 구매한 슈퍼유저는 그만큼 이득볼 수 있어야지. 유료아이템에 대한 각각의 효과도 있어야하고 유료 꾸밈에셋 세트완성 시에 효과 더 주기도 해야함. 이건 P2W라서 우리 철학을 붕괴시키는게 아님. 유저만족을 위함이지.

## 밸런스 담당이 제안했고 승인받을 사항

- 프리즘·리부트·스튜디오 3세트 × 3종, 상품당 ₩3,300, 모두 사면 ₩29,700입니다.
- 아이템당 상시 P +0.50%p, 고유 조건 충족 +0.25%p, 세트 완성 +0.75%p, 전체 완성 +1.00%p입니다. 한 세트는 상시 +2.25%·최대 +3%, 전체는 상시 +7.75%·최대 +10%입니다. 소유 기준 적용을 제안합니다.
- 기존 결정 기록의 꾸미기 상한은 +10% 이하이고, 이전 리뷰에서는 전체를 최대 +3%로 잡았습니다. 이번에는 +3%를 한 세트 최대치로 옮기고 전체를 최대 +10%로 두는 수치안을 검토받습니다. 정확한 가격, 품목 수, 효과율, 조건, 보유 기준, 구현 착수는 사용자 승인 대상으로 남아 있습니다.

## 검토할 항목

1. **구매 가치** — 9개 SKU 각각의 조건과 상시 효과가 이해 가능한지, 부분 구매와 세트 완성의 한계 이득이 명확한지, ₩3,300과 완성 보너스가 사용자 의도에 맞는지 평가해 주세요.
2. **검증 근거** — 풀세트 첫날 보유 가정과 실제 조건 발동을 구분해 확인해 주세요. 84일·프로필별 10시드·중앙값 및 8/10 기준을 원자료와 대조해 주세요. 표준 월간 패스 43.58일→44.00일, 화면 보상만 쓰는 월간 패스 47.00일·8/10→43.17일·10/10, 울트라 16.17일·8/10→15.75일·10/10을 함께 해석해 주세요. 부분·순차 구매와 화면 보상 보완 검증 중 어느 것을 착수 전 조건으로 둘지 판단해 주세요.
3. **코어·거래·UI 계약** — 상한 적용 전 가산과 실제 추가 지급의 차이, 기존 기록·복귀 정산·고정 시드 도전 영향, 영수증 재전송·보유권 저장·초기화·동기화·복원·환불, 기존 JSON 호환을 확인해 주세요. 현재 디버그 거래 범위와 이후 실제 Play 연결 범위를 나눠 평가해 주세요.
4. **재현 가능성** — 결론을 바꿀 가능성이 가장 큰 검증을 우선순위로 제시해 주세요. 문제를 찾으면 파일·행 또는 시드, 재현 방법, 수정 방향, 승인 전에 필요한 증거를 적어 주세요.

## 답변 형식

1. **권고 한 줄** — 승인 권고 / 조건부 승인 권고 / 보류 권고 중 하나를 고르고 근거를 한 문장으로 적어 주세요.
2. **주요 발견** — 중요도 순으로 근거, 유저 또는 저장·정산 영향, 고칠 부분을 적어 주세요.
3. **승인 항목 표** — 상품 수·가격, 아이템 효과·세트 보너스, 최대 +10%, 보유 기준, 구현 착수마다 권고와 승인 조건을 적어 주세요.
4. **사용자에게 요청할 최종 결정** — 지금 승인해도 되는 범위와 추가 검증이 필요한 범위를 구체적으로 제시한 뒤, 승인 / 조건부 승인 / 보류 중 직접 선택할 수 있게 한 문장으로 물어봐 주세요.

상품과 수치는 검토 제안이고, 구현 착수의 최종 승인권자는 사용자입니다. 이번 답변은 검토 결과로 제출해 주세요.
