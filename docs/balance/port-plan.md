## 재현

```sh
./gradlew -p core test
./gradlew -p tools/economy-sim run --args="balance-report $(pwd)/docs/balance"
./gradlew -p tools/economy-sim run --args="balance-commerce $(pwd)/docs/balance"
```

프로필은 84일간 매일 4회씩 15분 플레이한다. 게임 화면과 시뮬레이터는 같은 `Engine`, `Shop`, `RuleSet`을 사용한다. 시뮬레이터는 최고 기대 수입 플레이, 정해진 구매·덱·환생 선택, 매일 미션 완료를 가정한다. 주차 도달 검증과 별도로 보급형 유저 행동과 실제 결제 전환은 출시 데이터가 필요하다.

## 기기 확인

GitHub Actions의 API 30 에뮬레이터에서 기존 좌표 스와이프 스모크 후 디버그 APK의 WebView에 CDP로 연결한다. 초기화가 가능한 고정 시드 저장 파일로 테스트를 시작하고 상품·실제 화면 버튼·덱·연쇄·재실행·공장 초기화를 검증한다. 단계별 기기 스크린샷과 합성 계정의 저장 JSON은 `android-smoke-screens` 아티팩트에서 확인할 수 있다.
