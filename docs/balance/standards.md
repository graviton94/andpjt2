# 밸런스 검산식

## 성장과 정산

앱이 쓰는 정수식과 정산 시점으로 검산한다. 레벨 곡선에 근사 다항식을 적용할 경우 레벨 경계에서 판정이 뒤집힐 수 있다.

| 지표 | 기준식 | 검산 |
|---|---|---|
| 레벨 진입 P | `Q₂ = 30`. `L < 25`면 `Qₗ₊₁ = roundEven(Qₗ × 2330/1000)`. `L ≥ 25`면 `Qₗ₊₁ = roundEven(Qₗ × (2330 + 5(L−24))/1000)`. | 각 항을 정수로 반올림하고 .5가 정확히 나오면 짝수를 선택한다. Lv2·3·4는 30·70·163 P다. FastBoot k레벨의 실제 진입선은 `ceil(Qₗ × (9/10)^k)`. |
| P 회계 | `다음 지갑 = 지갑 + 지급 P − 소비 P`. `다음 회차 P = 회차 P + 지급 P`. | 강화 비용으로 Lv가 내려가지 않는다. 공장 초기화와 동기화가 회차 시작값을 설정한다. |
| 단위 제거 P | `floor(알림 수 × 앱 가치 × 제한된 덱 시너지 × 누적 알림 배율 × 연쇄 × 프로 × 앱 효과 × ★ × 부스트)`. | 폭발·파동은 단위 제거 결과들을 합산한다. 합산 후 앱별 스와이프 효과와 레벨 상승 상한이 적용될 수 있다. |
| 프리미엄 ★ | 앱 가치 `2^★`. 티어 T의 ★5 총가격 기준은 `6000 × 2^((T−1)/4.5) / 4`. 각 단계는 5%, 10%, 17%, 28%, 40%의 비중이다. | 각 ★의 정수 가격은 `premiumCost`와 `app-costs.csv`를 사용한다. 선택권은 ★1·★2의 잠금과 잔여 수량을 지킨다. |
| 배터리 | 기본 충전 3,000ms에서 배터리 백업 강화 레벨마다 200ms를 뺀다. 배터리 부족 알림이 남으면 간격이 30% 늘고, 속도권은 충전 간격을 줄인다. | 오버클럭과 속도권 중 빠른 것이 적용된다. 직접 플레이의 시간 하한은 기본 1,000ms다. |
| 공장 초기화 | `max(0, 새 최고치의 누적 백업파일 − 이번 주기의 지급 누적)`에 다음 초기화 부스트와 속도권 혜택을 적용한다. | 같은 회차 성과로 파일을 반복 획득할 수 없다. 동기화 시 Account가 남고 백업 주기는 다시 시작한다. |
| 데이터 회계 | `잔액 = 무료 지급 + 결제 귀속 지급 − 소비`. 첫 데이터 팩은 `기본 수량 + min(기본 수량, 1200)`. | 모든 데이터 팩이 첫 구매 혜택 1회를 공유한다. 저장한 결제 ID의 재전송은 차단한다. 광고 ID는 최근 7 UTC 날짜와 최대 84건까지 재지급을 차단한다. |

## 연속 출석의 구매력

**최근 확정된 30일 연속 출석판 기준.** 아래 금액은 동일 데이터를 구매하는 경우의 비교이며 현금화 값은 없다. 원화 비교에는 첫 구매 보너스 전 ₩12,000 → 데이터 1,200의 단가인 개당 ₩10을 사용했다.

| 구간 | 데이터 | 사용권을 모두 쓸 때의 데이터 대체량 | ★ 선택권 |
|---|---:|---:|---:|
| 10일차 당일 | 200 | 230 | 0 |
| 20일차 당일 | 300 | 160 | 1 |
| 20일 연속 합계 | 750 | 870 | 1 |
| 30일 연속 합계 | 1,520 | 1,650 | 3 |

- 10일차의 데이터 200은 동일 구매비용 ₩2,000이다. 해당 티켓을 모두 사용하면 추가로 데이터 230의 구매를 대체한다.
- 20일차의 데이터 300은 ₩3,000이다. 시간 도약권 2장을 모두 사용하면 데이터와 티켓으로 ₩4,600을 대체한다. 선택권의 실제 가치는 사용할 앱의 다음 ★ 단가다. 후속 구매 의향을 계산할 때 유저가 쓸 확률과 원래 구매했을 확률을 적용한다.
- 20일 연속 접속의 데이터와 티켓 전량 사용 상한은 ₩16,200에 선택권 1장을 더한 값이다. 데이터만 비교하면 ₩7,500이다.
- 30일의 20개 날짜에 방문을 균등하게 배치하면 동일한 20회 방문으로 연속 출석이 최고 2일까지 이어진다. 고정 방문 시나리오의 무과금 유저는 데이터 330을 받아 연속 유저보다 420 적었다. 수입 차이는 연속 방문이라는 조건의 효과를 나타낸다.

재현 데이터는 [attendance-values.csv](attendance-values.csv) 및 [commerce-scenarios.csv](commerce-scenarios.csv)에 있다.
