# 꾸미기 점수 보너스 설계안

꾸미기는 알림판 테마, 기물 외형, 개인 기록 카드의 표현을 바꾼다. 수집 보너스는 **개인 꾸미기 기록에 최대 +5%**를 적용한다. 진행에 쓰는 P 수입 가산율은 **0%**다. 게임 화면에 기본 기록과 꾸미기 적용 기록을 각각 표시한다. 공용 순위의 비교 기준은 기본 기록이다.

## 수집과 상한

- 무과금 경로로 획득 가능한 꾸미기 5개가 각각 1%p를 더한다. 같은 꾸미기의 색상 변형이나 중복 구매는 수집 수에 포함하지 않는다.
- `보너스율 = min(5, 보너스 대상 수집 수)%`. `개인 꾸미기 기록 = floor(최고 스와이프 P × (100 + 보너스율) / 100)`.
- 개인 꾸미기 기록은 화면에 표시할 때 계산한다. 기본 최고 기록, 지갑, 회차 P, 오프라인 수입, 자동 플레이, 레벨, 백업파일 및 GB는 기존 엔진 정산 결과를 사용한다.

## 유료 판매안

유료 판매를 채택하면 외형 팩으로 묶는다. 판매가는 개별 테마 ₩3,300과 테마·기록 카드 묶음 ₩5,500을 후보로 둔다. 유료 색상과 이펙트는 수집 보너스 자격을 빠르게 채우거나 추가 배율을 부여하지 않는다. 무료 획득으로 동일한 +5%에 도달할 수 있다.

## 시뮬레이션

원본과 최대 수집(+5%) 표시 점수를 동일한 스와이프에서 계산한다. [10개 시드 데이터](audit-seeds.csv)의 `record_p`, `cosmetic_record_5pct`, `lv124_day`, `cosmetic_lv124_day`에서 비교한다. 꾸미기 환산은 거래 및 레벨 상태에 전달하지 않으므로 각 행의 Lv124 경과일이 같다. [프로필 판정표](audit-gates.csv)로 출시 전 진행 범위를 확인한다. 본선 게임에 반영할 때는 UI, 수집 저장 호환성, 기록 표시를 별도 승인에서 다룬다.
