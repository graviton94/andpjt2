# EX 꾸미기 개별 효과와 세트 보너스

EX는 현금으로 구매하는 비소모성 꾸미기다. 출시안은 프리즘·리부트·스튜디오 세트에 각각 세 개씩, 총 아홉 개다. 항목당 **₩3,300**을 제안한다. 소유한 EX마다 일반 플레이 스와이프 P **+0.50%p**와 고유 조건 충족 시 **+0.25%p**가 누적된다. 세트 완성은 **+0.75%p**, 세 세트 전체 완성은 **+1.00%p**를 추가한다. 장착한 외형은 자유롭게 바꿀 수 있다.

## 개별 상품

| 세트 | 상품 · 외형 | 개별 조건 · 충족 시 P +0.25%p |
|---|---|---|
| 프리즘 | 프리즘 궤적 `prism_trail` | 해당 스와이프에서 2연쇄 이상 |
| 프리즘 | 프리즘 충격파 `prism_wave` | 해당 스와이프에서 과부하 파동 발동 |
| 프리즘 | 프리즘 테마 `prism_theme` | 해당 스와이프에서 기물 합치기 발생 |
| 리부트 | 리부트 프레임 `reboot_frame` | 계정에 유효 공장 초기화 또는 GB 동기화 이력 |
| 리부트 | 리부트 테마 `reboot_theme` | 해당 스와이프 시작 시 현재 회차 Lv25 이상 |
| 리부트 | GB 동기화 효과 `reboot_sync` | 계정에 GB를 받은 동기화 이력 |
| 스튜디오 | 스튜디오 덱 외형 `studio_deck` | 활성 앱이 4개 이상 |
| 스튜디오 | 스튜디오 ★ 외형 `studio_star` | 프리미엄 ★가 붙은 앱을 덱에 장착 |
| 스튜디오 | 스튜디오 프로 외형 `studio_pro` | 프로 버전을 연 앱을 덱에 장착 |

‘유효 공장 초기화’는 백업파일을 얻은 초기화다. 이후 GB 동기화로 이번 주기의 초기화 횟수가 리셋돼도 동기화 이력이 리부트 프레임 조건을 충족한다. 스튜디오 두 장착 조건은 회차에 따라 덱이 변경될 때 다시 평가한다.

세트 완성 외형은 프리즘의 연쇄 피니시, 리부트의 공장 초기화 전환, 스튜디오의 전용 최고 기록 카드다. 각 세트의 상시 P +0.75%p는 완성 외형을 선택하지 않아도 적용된다.

## 구매 단계별 누적

| 보유 예시 | 누적 구매가 | 상시 P | 조건 포함 최대 P |
|---|---:|---:|---:|
| 개별 1개 | ₩3,300 | +0.50% | +0.75% |
| 개별 2개 | ₩6,600 | +1.00% | +1.50% |
| 개별 3개 · 각 세트에서 하나씩 | ₩9,900 | +1.50% | +2.25% |
| 한 세트 완성 | ₩9,900 | +2.25% | +3.00% |
| 두 세트 완성 | ₩19,800 | +4.50% | +6.00% |
| 여덟 개 · 마지막 한 개 남음 | ₩26,400 | +5.50% | +7.50% |
| 전체 세 세트 완성 | ₩29,700 | +7.75% | +10.00% |

이전 +3%는 한 세트의 최대 효과로 배정했다. 전체 구간은 기존 꾸미기 수입 상한 안의 제안이다. 풀세트에서도 스와이프마다 조건을 평가해 +7.75%에서 +10.00%를 적용한다. [꾸미기 수입 상한 결정](../bible/11-decision-log.md)

구매 확인 화면은 항목 가격, 지급 외형, 상시·조건부 가산을 표시한다. 해당 구매가 세트를 완성하면 이번 구매의 상시 상승분에 세트 효과까지 합쳐 보여준다. 예를 들어 프리즘 2개 보유자가 세 번째를 사면 상시 +1.00%에서 +2.25%로 올라간다. 한 SKU는 계정 한 번 구매이고, 소유 상태와 세트 진척은 개별로 보여준다.

## 지급과 기록

`가산 bp = 50 × 보유 수 + 25 × 조건 충족 수 + 75 × 완성 세트 수 + 100 × 전체 완성 여부`

`지급 P = min(기존 레벨 상한 여유, floor(스와이프 기본 P × (10,000 + 가산 bp) ÷ 10,000))`

기존 스와이프 효과를 계산한 뒤 가산하고 레벨 상한을 적용한다. 일반 및 자동 스와이프에 동일하게 적용한다. 결과는 지갑, 회차 P, 개인 스와이프 최고 기록, 최근 수입률에 들어간다. 오프라인 정산과 시간 도약은 최근 수입률을 통해 반영된다. 고정 시드 일일 도전은 동일 조건으로 기록을 비교한다.

## 승인 후 구현 범위

- 상품 ID별 보유권은 계정에 보관하고 공장 초기화와 GB 동기화 이후에도 복원한다. 세트 진척과 수입 가산은 보유권에서 계산한다. 기존 저장은 빈 EX 보유권으로 연다.
- 앱의 디버그 거래에서 신규 구매, 영수증 재전송, 중복 구매, 초기화, 복원을 검증한다. 실제 Play 연동 시 검증된 비소모성 SKU의 환불·회수는 소유 목록에 반영하고, 연결된 세트 효과를 다시 계산한다.
- 화면 담당에게 SKU별 가산, 세트 진척, 보유 효과, 구매 후 가산 변화, 정산에 실제로 추가된 P를 넘긴다. 스와이프 표시의 실제 EX 가산분은 동일한 레벨 상한을 적용한 EX 전후 지급 P 차이다.

## 백테스트

기존 코어 사본에서 첫 세션부터 아홉 개의 보유권을 가정한다. 각 스와이프에서 실제 조건을 평가한다. 이 모델은 최대 +10%를 항상 적용하는 모델과 구별된다. 기존 프로필에 EX를 추가한 시나리오이므로 무광고 행의 EX 쪽은 EX 단독 구매자, 광고 행의 EX 쪽은 EX 구매 광고 유저를 의미한다. 84일, 하루 4회 × 15분, 프로필별 시드 1–10을 사용한다.

| 플레이 정책 | Lv124 목표 | EX 미보유 중앙값 · 구간 내 | 풀세트 중앙값 · 구간 내 | 같은 시드에서 빨라짐 / 같음 / 늦어짐 |
|---|---:|---:|---:|---:|
| 무광고 | 66–84일 | 75.42일 · 9/10 | 71.08일 · 8/10 | 8 / 0 / 2 |
| 광고 하루 5회 | 49–63일 | 56.09일 · 10/10 | 55.50일 · 9/10 | 8 / 0 / 2 |
| 월간 패스 | 35–49일 | 43.58일 · 10/10 | 44.00일 · 10/10 | 4 / 2 / 4 |
| 터보 | 24–32일 | 27.17일 · 10/10 | 26.67일 · 10/10 | 4 / 1 / 5 |
| 울트라 | 11–17일 | 16.17일 · 8/10 | 15.75일 · 10/10 | 5 / 3 / 2 |
| 월간 패스 · 화면 보상만 | 35–49일 | 47.00일 · 8/10 | 43.17일 · 10/10 | 9 / 0 / 1 |

다섯 프로필과 화면 보상만 사용한 월간 패스 모두 중앙값과 8/10 기준을 충족했다. EX 단독 구매자의 구간 밖 시드 2개는 각각 61.00일과 61.17일에 도달했다. 표준 월간 패스는 EX 미보유보다 중앙값이 0.42일 늘었다. P 증가가 강화와 환생 시점을 바꾸므로 구매 확인창에는 P 수입 가산율을 표시한다. [풀세트 시드별 원자료](cosmetic-ex-collection-seeds.csv)

출시안 아홉 SKU의 보유 조합 512개를 계산해 SKU를 하나 더 얻을 때 상시 가산이 최소 0.50%p씩 증가하고, 모든 조건이 겹쳐도 최대 +10.00%임을 확인했다.

## 재현

```sh
python3 tools/economy-sim/cosmetic-probe.py /tmp/ex-collection --ex-owned all
python3 tools/economy-sim/cosmetic-probe.py /tmp/ex-collection-visible-pass --ex-owned all --profiles Pass --available-rewards
```

개별 구성을 검증하려면 `--ex-owned prism_trail,prism_wave,prism_theme`처럼 보유 SKU를 지정한다. 무보유 기준과 이전 일괄 +3% 실험은 기존 보고서에 있다. [기준 실험](offline-pass-review.md)
