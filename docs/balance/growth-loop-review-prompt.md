# 다른 세션에 보낼 무한 증분·환생 가속 검토 요청

알림 청소부의 새 밸런스 후보를 검토해 주세요. 저장소는 graviton94/andpjt2, 브랜치는 ccr-balance-port입니다. 전체 결과는 docs/balance/GROWTH-LOOP-REPORT.md, 화면 계약은 docs/balance/api-changes.md에 있습니다. [통합 보고서](GROWTH-LOOP-REPORT.md) · [화면 계약과 응답 예시](api-changes.md)

## 사용자가 직접 방향을 바꾼 사항

1. Lv124의 주차가 제품 통과 기준이었던 이전 결정을 교체했습니다. 회차 내내 숫자가 커지고, 환생 뒤에는 같은 구간을 더 빠르게 통과하며 새로운 강화에 손이 닿는 게임입니다. 무한 강화는 처음부터 열고 시간 대비 비용으로 조정합니다.
2. EX는 유료 전용·비확률형 3세트×3SKU, 개당 ₩3,300이며 소유·세트에 따라 누적합니다. 덧셈과 +10% 한도는 폐기했습니다. 7·14·28·56일 같은 시드에서 1세트 +0.5자리, 풀세트 +1자리의 누적 P 우위가 목표입니다. 누적 파일·GB와 최고 Lv도 봅니다. 구독 상품은 장기적으로 절대 진행에서 앞서야 합니다.
3. 도전에는 EX를 적용하지 않고, 시작 보유 ★당 0.1%p·최대 3%를 점수에 반영하는 안은 승인했습니다. ValueCap 폐기와 기존 매입액 일회 환급도 승인했습니다. 운영 이식은 격리 검증과 사용자 확인 뒤입니다.
4. 화면은 큰 수를 문자열로 표시하고 코어에서 계산한 구매·기록 불리언을 씁니다. 화면 담당은 현재 정확 문자열로 먼저 전환할 수 있습니다.

## 확인해 줄 것

1. 앱 수입 ×1.20, 가격 ×1.30과 회차별 가격 인덱스가 구매 시간을 안정화하는지 검토합니다. P는 모형에서 개선됐고 실제 코어에서는 초기부터 전부 인덱싱한 가격이 터보의 56일 누적 P를 크게 줄였습니다. GB 대기는 15% 권리액 일부 정산에서도 전부 10분을 넘었습니다. 저단계 가격과 새 강화 구간의 가격을 어떻게 맞출지 적어 주세요.
2. A의 수입·환생 지급과 B의 수입·할인·오프라인을 같은 조건에서 점검합니다. 하루 15분 30시드 무광고 풀세트는 A +2.66/B +3.96자리였습니다. 하루 45초에서는 +0.22/+0.26자리에 그쳤습니다. 터보의 A 풀세트는 1세트보다 뒤졌습니다. 실제 구매 효용을 접속량·자연/고정 환생·지급 상한·GB 해금 여부에 따라 설명해 주세요.
3. A·B의 확정 가격과 장기 터보·울트라 원당 효과를 같은 시간축에서 확인합니다. 실제로 끝난 측정과 장기 가정을 구분합니다. 56일과 168일 구간, 낮은 참여량 플레이어를 따로 봅니다.
4. 화면은 지급된 EX 추가 P·파일·GB, 정확 문자열, 짧은 표시, 구매·기록 불리언을 받을 수 있는지 확인합니다. e308을 넘는 경우와 화면 코드 연동 후의 복귀·재실행 검증 계획을 작성해 주세요.
