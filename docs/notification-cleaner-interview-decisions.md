# 알림 청소부 인터뷰 결정본

2026-11-22 · 앱 교체와 비장착 강화를 확정한 시점

**이 문서는 본편 인터뷰에서 합의한 최신 규칙을 기록한다.** 상충하는 항목은 이 결정본을 우선한다. 제품 목표, Android 설계 방향, 실기기 검증과 출시 순서는 [추가 개발계획서](notification-cleaner-production-plan.md)를 함께 본다.

## 확정한 규칙

### 한 줄로 여는 연쇄

- 가로로 한 줄을 밀면 수동 행동력 1칸을 쓴다. **같은 앱 두 줄이 맞닿으면 터진다.** 행의 묶음 수량과 해당 앱의 배율이 클수록 폭발 결과가 커진다.
- `A / C / B / C / A`에서 저벨류 `B`를 밀면 `C+C → A+A`가 이어진다. 작은 알림을 일부러 지워 고벨류 알림을 연결하는 판단이 한 수의 재미다.
- 보통 연쇄에서도 빈자리에 내려오는 새 알림이 짝을 만들면 **현재 연쇄에 즉시 합류한다.** 내가 열어놓은 연쇄가 보충 운과 특수 블록을 만나 예상보다 오래 이어질 수 있다.
- 작은 스와이프도 타격감과 즉시 보상을 준다. 큰 폭발은 낮은 가치의 알림을 치우고 고벨류 묶음을 남겨 준비할 수 있다. 연쇄 수와 처리량이 실제로 커질수록 빠른 설정과 상태표시줄까지 붕괴 연출이 퍼진다.

### 앱 슬롯과 점수

- 앱을 계속 구매하고 수집할 수 있다. **일반 앱과 특수 알림은 별도 활성 슬롯**에 장착한다. 초반에는 진행에 따라 슬롯을 늘리고, 이후에는 각각의 상한을 두어 보유한 후보 중 무엇을 넣을지 선택하게 한다.
- 각 앱에 사용자권역과 카테고리를 부여한다. **같은 연쇄에서 실제로 터진 앱**을 기준으로 권역 시너지와 카테고리 시너지가 발동하며, 두 배율은 서로 곱한다. 장착은 어떤 앱이 보드에 등장할지 결정한다.
- 앱별 강화는 그 앱이 터질 때의 점수 배율을 키운다. 특수 알림은 해금하면 새로운 연쇄 경로를 열어주고, 강화하면 해당 블록의 배율이나 고유 보상이 커진다. 새 특수 종류의 해금은 비교적 큰 투자로 둔다.

### 선투자와 주력 교체

- 신규 앱은 해금 즉시 고유 기능을 쓸 수 있다. 처음 주력 조합에 끼우면 기존에 충분히 강화한 앱을 쓸 때보다 **비교 가능한 플레이에서의 총보상이 낮다.** 새 기능의 매력이 먼저 보이고, 꾸준히 키운 뒤에 실전 보상이 따라오는 구조다.
- **획득 재화로 강화 메뉴에서 장착 여부와 관계없이 보유 후보를 강화할 수 있다.** 주력 조합의 수익으로 새 후보를 선투자하고, 점차 써본 뒤, 기존 앱을 앞서는 조합이나 상황이 생기면 교체한다.
- 교체 시점은 앱별 배율과 권역·카테고리 시너지, 해당 조합에서 실제로 터지는 정도로 판단한다. 유저가 비교하는 핵심은 여러 스와이프에 걸친 **조합 전체의 보상**이다.

### 특수 알림과 행운

- 기본 경로는 스와이프로 특수 게이지를 채우는 방식이다. 게이지가 차면 장착한 특수 알림 중 하나가 다음 보충에 등장한다. 가끔은 예고 없이 특수 알림이 나오는 깜짝 이벤트도 발생한다.
- **특수 블록이 다른 특수 블록을 터뜨릴 수 있다.** 한 스와이프에서 엮인 블록은 각각 한 번씩 전부 효과를 발동한다. 폭발을 만드는 블록, 점수를 키우는 블록, 다음 행동 기회를 주는 블록처럼 보상은 블록마다 다르다.
- **재난경보**는 근처 알림을 함께 터뜨릴 수 있다. `A / B / 재난경보 / A`에서 `B`를 밀면 옆 경보가 점화되고, 경보 자리가 열리며 `A+A`를 연결할 수 있다. 발동하면 알림창을 멈추고 전용 씬을 띄운다. **플레이어가 눌러 시작한 시점부터 기본 5초간 연타**해 이번 연쇄의 배율을 모은다. 시간이 끝나면 모은 배율을 적용해 연쇄를 방출한다.
- **보조배터리**는 행동력을 회복시킨다. 가상 상태표시줄의 배터리 아이콘이 차오르는 식으로 보상을 표현한다. 재난경보가 보조배터리까지 터뜨리면 연타 배율과 행동력 회복이 같은 연쇄에 모두 반영된다.
- **행운은 보충으로 현재 연쇄를 이어줄 알림이 나올 가능성**에 작용한다. 세 층을 함께 쓴다.

| 층 | 성장·조정 방법 |
|---|---|
| 기본 행운 | 활성 앱 슬롯 수에 맞춰 기본 확률을 조정한다. 앱 종류가 늘었을 때 연쇄 빈도가 지나치게 떨어지는 구간을 줄인다. |
| 조합 행운 | 장착한 앱과 특수 알림의 효과로 달라진다. 길게 이어지는 조합과 한 번 붙으면 크게 터지는 조합이 가능하다. |
| 계정 행운 | 획득 재화로 영구 강화한다. 어떤 조합을 쓰더라도 적용한다. |

### 방치와 행동력

- 화면을 켜둔 동안 자동 정리는 낮은 가치의 알림 위주로 천천히 치워 소소한 P와 XP, 소연쇄를 만든다. 수동과 자동은 공통 행동력을 쓰는 방향으로 잡고, 자동이 일부를 남기는 기준을 검증한다.
- 행동력의 기본 회복은 시간 충전이다. 연쇄에서 받는 추가 행동력은 보조배터리처럼 그 보상을 가진 특수 블록을 통해 얻는다.

## 검증용 가안

| 항목 | 첫 실험에 사용할 안 |
|---|---|
| 자동 정리 | 최대 12칸, 9칸 이상일 때만 자동으로 1칸 소비해 수동용 8칸을 남긴다. 대형 연쇄나 특수 점화가 보이는 자리는 수동 개입 기회로 보존한다. 자동 주기와 보호 기준은 비교한다. |
| 보조배터리 | 한 번 발동하면 행동력 1칸 회복. 강화 시 회복량, 발동 범위, 상한에서의 처리 방식은 테스트한다. |
| 깜짝 특수 이벤트 | 기존 게이지 충전분을 유지한 채 깜짝 특수 알림을 추가로 등장시킨다. 이벤트 전용 후보를 둘지는 별도로 결정한다. |
| 행운의 체감 | 기본·조합·계정 행운의 합성식, 상한과 후반 효율을 여러 활성 슬롯 수에서 비교한다. 보충 한 번의 명중률과 전체 연쇄가 길어질 확률을 따로 측정한다. |
| 교체 시점 | 같은 출발 보드와 시드, 동일한 시간 또는 스와이프 수로 기존 조합과 새 후보를 비교한다. 해금 직후, 중간 투자, 교체 시점에서 P 수익과 점수를 따로 잰다. |

## 남은 결정과 검증

| 순서 | 남은 것 |
|---|---|
| 1. 성장과 경제 | 첫 5분·첫날·일주일의 첫 슬롯 확장, 첫 특수 해금, 첫 주력 교체 시점. 앱·특수 초기 슬롯과 상한, 구매가·강화 비용·성능 곡선, 다음 후보로 갈아타는 데 걸리는 시간. P·XP·점수 공식과 자동·수동 수익 차이. |
| 2. 판정과 확률 | 한 줄을 민 직후의 특수 발동·병합·보충 순서, 같은 파동의 동시 발동 우선순위, 큰 연쇄의 종료·압축 기준. 여러 앱이 동시에 만족할 때의 권역·카테고리 발동 문턱과 중복 계산. 행운의 합성식과 특수 게이지 수치. 고벨류 묶음을 오래 남겨둔 경우의 판 변화. |
| 3. 특수 카탈로그와 UI | 첫 출시 특수 블록의 수와 역할, 등장률, 강화 보상. 경보 시작 대기에서 입력 없이 머물거나 앱을 닫았을 때의 처리, 첫 입력의 연타 집계, 연타→배율 곡선, 조작 대체 방법. 동시에 여러 조작 씬이 생길 때의 순서. |
| 4. 복귀·수익·경쟁 | 화면을 떠난 동안의 정산, 행동력 소진 시 흐름, 보상형 광고의 제안 조건, 과금 상품과 무료 진행의 경계. 공개 순위에서 계정 행운·앱 강화·조합·시드를 표준화하는 방식. |
| 5. 구현과 출시 검증 | 재현 가능한 판정·저장과 중복 지급 방지, 주요 시드의 판정 테스트, 실기기 햅틱과 가독성, 접근성, 파일럿 지표와 출시 범위. |

**인터뷰 재개 지점** · 성장과 경제부터 이어간다. 첫 주력 교체를 몇 번의 투자와 어느 정도 플레이 시간에 처음 체감시키고 싶은지 정한 뒤, 해금가·강화 비용·교체 수익을 가안으로 놓고 비교한다.
