# 밸런스 세션 지시서 v1.5 — 화면 행동 기준 재밸런싱 (11-28)

v1.4(372a38b) 잘 받았다. "시뮬레이터가 출시 화면에 없는 성장 경로를 쓴다"는 발견이 이번 판의 핵심이었다. **결정: 그 경로를 이번 출시 빌드에 연결한다.** 화면 세션이 연결을 마쳤다.

## 0. 먼저
- `git fetch origin ccr-9efafd3c-bh5fdz && git merge --no-edit FETCH_HEAD`
- 상품 ID 11개, 가격, Play 상품 설명의 패스 구성은 **바꾸지 마.**

## 1. 화면에 연결된 것
계약은 `docs/balance/api-changes.md` "v1.4 화면에서 여는 회차 내 성장"을 따른다.

| 행동 | 화면 위치 | WebSession |
|---|---|---|
| 앱 프로 구매 | 강화 시트 앱 줄의 PRO 버튼 | `buyPro(app)` |
| 이벤트 카드 구매·장착·해제 | 덱 시트 '이벤트 카드' | `buyEvent(card)` (빈 칸이면 자동 장착) · `setCards(cards)` |
| 알림창 강화(어시스트 4종) | 강화 시트 '알림창 강화' | `buyAssist(item)` |
| 방해 금지 발동 | 위쪽 방해 금지 버튼(카드 장착 시) | `dnd()` |

브라우저에서 구매·장착·해제·발동을 모두 확인했다. 회귀 테스트도 통과했다.
- 판 강화가 이 표의 어시스트 4종(과부하 깊이, 샌드위치, 넓은 알림창, 와일드) 말고도 있다면 알려라. 화면에 더 연결한다.
- 시뮬레이터가 화면에 없는 행동을 또 쓰면 목록으로 보고해라. 연결할지는 화면 세션이 정한다.

## 2. 해야 할 일
1. `SIM_SCREEN_ONLY=1`의 허용 행동에 위 다섯 가지를 넣어라. 시뮬 행동 모델이 화면에서 실제로 할 수 있는 것과 같아야 한다.
   - 플레이어가 카드를 고르는 규칙(어떤 카드를 장착하는지)을 시뮬에 명시하고 보고서에 적어라.
2. 화면 기준으로 5프로필 × 8시드 × 84일을 다시 돌려 v1.4 표 전체를 다시 판정해라. 대상은 월간, 광고 가속, 해금 공백, 오프라인 몫, 손맛, 첫 6티어, 첫 동기화다.
3. 그래도 미달인 항목은 v1.4 지시서 1~3절 방침(공통 비율 가산, Lv69~76 배치 우선, 손맛 하한 45% 유지 근거)대로 맞춰라.
4. 앞으로 출시 판정은 **화면 기준 시뮬만** 인정한다. 기존 모드는 참고용으로만 남겨라.

## 3. 보고
v1.4와 같은 형식. 추가:
- 시뮬 카드 선택 규칙
- 화면 기준 vs 기존 모드 비교표(같은 시드)
- 바뀐 한국어 문구(키 `#` 형태)
- 출시 판정과 남은 위험

결정이 필요한 것(목표 자체 변경, 가격·상품 변경, 효과 의미 변경)만 묻고 나머지는 끝까지 진행해.
